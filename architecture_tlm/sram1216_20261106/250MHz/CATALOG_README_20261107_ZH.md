## 1. 为什么100MHz新Attention还不是已验证默认

100MHz中PV128＋归约32＋共享QK是优先候选，宏级接口已能接入，条件面积约41.46mm²。当前已验证参考仍为旧Attention约52.62mm²，理由是实际未闭合项：

- 新PV4电路RTL通过，但门级回放仍有未知值X；不能用它作为已验收硬件后端。
- QK共享切片通过，但真实SRAM K布局到共享输入接口的重排／供数尚未完整验证，当前TLM仍沿旧供数宏。
- 新组合尚未完整36层回放；新增mux、route及PV状态选择/门控的最终PPA未补齐。

这不代表方案已被否定，也不要求所有无关电路做完才能研究。它可以显式作为候选运行；不能把候选的41.46和模块时序说成新硬件已经实现的结果。本次不改变100MHz的这一状态。

## 4. Attention尚未完成的部分

旧九模块已有TT100／TT250配对任务：FMA16/64、Ising、V控制、V累加16、数字Softmax systematic/R8 GF64、SparQ norm16/topK16。18项中17正常退出；FMA64/250超时，已有12/15功耗窗口，缺seed1009的backpressure、idle_hold、idle_toggle。

自动归档38617015也超时，仅留下882150263B报告包、没有完整归档SHA。模块summary和原报告索引已存在，但尚不能作为本目录的完整、可验收系统价格。SparQ文件格式不同，通用windows列表为空不等于没有仿真。本目录保留9模块的元数据状态，**不提前把其价格填入完整TLM**。

面向新缩面积结构还缺：PV4先修100MHz门级X，再做TT250；共享QK包装及真实供数要按4ns验证；32路末端归约先查已有FP32 ADD的TT250单价与II，不盲目要求整阵列重仿。

## 5. 组装前待决定，不在本轮替用户定值

1. 普通计算池路数：320／640仅作为候选集合。若取320，不能从中借512路做QK，必须重分KV组/批次并核供数和归约。
2. SRAM时钟、bank端口、译码互连、DMA返回通路与250MHz算子的边界：已有宏表征可复用作输入，250MHz宿主端口争用/回压尚未接合。
3. 格式转换、RMSNorm/RoPE/残差等250MHz参数先盘点已有数据；“本目录未绑定”不等于该模块从未仿真。
4. 短T8/T32、物理核数量、门控/idle状态与随机前端消费率：不依据T64或100MHz直接推导新的整机功率。

上述信息补齐后再建立独立250MHz调度与完整TLM。本轮不启动补测或整机任务，不修改198/204的原始文件或队列，不影响100MHz结果。
