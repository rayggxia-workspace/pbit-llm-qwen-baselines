# Qwen固定W8：多档缩放与粗细分层的同协议比较

接续Issue46/PR47；不修改此前IID实现/执行快照或Attention成员任务。所有24个FFN替换，原BF16 SDPA不变，无训练。沿用同一历史64×64 symmetric INT8解码权重，不做权重概率重编码；g/u共享x抽样，连续FP32 SiLU(g)×u后z独立重编码，输出BF16。这里只评估数值质量，没有新RTL/PT/PPA或TLM能效数据。

## 两个不同的“分”

- **幅度档数B**：同一64通道组的动态顶档S为absmax向上取二次幂，下档S/4、S/16……。每元素选能容纳它的最小档，不搬移通道、不主动删除极值。测B=1/2/3/4/6/8；另有旧dynamic64 absmax对照。幅度仍为q8/256加符号，精确满幅用独立恒1语义。
- **采样区间数K**：把8位均匀门限0..255等分K层，每层独立取T/K个层内均匀随机整数（有放回）。同组64路、跨幅度档共享门限。K=1为原自然IID；K=T时每层取1次，是此前细分层。K>1不再是IID序列，也不依赖挑选种子或固定抖动。

例如总采样T64：K4为4层、每层16次、每次6bit层内抖动；K16为16层、每层4次、每次4bit抖动；K64为64层、每层1次、每次2bit抖动。输入概率在一帧内固定，因此帧内先后顺序不影响本版精确归约；此论证不能移植到状态每拍变化的Ising更新。

## 为什么可能叠加

对一个输入幅度恢复值，设区间宽w=256/K，边界位置u=(q mod w)/w，则估计方差为

`恢复值方差 = S² × u(1-u)/(T×K)`。

多档缩放减小恢复尺度S，分层减少频数波动，作用不同。对同组带符号加权输出也要保留各lane的协方差；不能独立抽每lane的Binomial。精确分布采样器只是加速模拟正确联合计数，不代表硬件只需一次软件随机调用。

对固定线性输出f(R)，IID方差还包含“不同区间的平均输出之间的方差”；等额分层消去这部分。更细的嵌套分层使局部线性方差不增加，但非线性SwiGLU及跨层传播使整网PPL不必单调。

此前Llama2细分层完整结果不是Qwen基线：模型/固定尺度/stride/目标数均不同，旧表标准差还是样本标准差，不能直接按数字排名。

## 硬件边界

幅度档需要log2(B)向上取整的档号、组顶档指数和跨档准确对齐；原W8步长未强制二次幂。采样分层需要区间控制状态和层内随机字，若已有流周期计数器可研究复用，但未验证额外控制为零成本。PRNG状态/时钟功耗不一定随输出位数同比下降。相同T时主阵列拍数不变；若以更短T取得同质量，才能进一步按新调度估算整机时间/能量。

K=T=256等价所有8位门限完整遍历，不再需要随机性；T128细分层在幅度码层面接近低位随机舍入。它们保留为对照，不冒称完全自然物理IID，也不能据此断言随机源比确定性低位矩阵更省电。
