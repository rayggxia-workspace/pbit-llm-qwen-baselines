# 双随机误差原因及与DS-CIM的公平比较

2026-10-18，Issue30已有47项输出的只读诊断；没有新增模型、GPU、训练或RTL/PT实验。结果范围仍为同一128-token前缀，不能把下列诊断当完整WT2因果消融。

## 局部方差能够严格说明什么

固定同一个线性层的输入、编码尺度及量化权重。输入概率p_i，权重概率r_oi=abs(code)/127，满幅乘积系数c_oi含输入尺度、127倍权重步长及符号。当前每连接独立权重流满足：

`Var(y_dual,o) = Var(y_fixed,o) + (1/T) sum_i c_oi^2 p_i r_oi(1-r_oi)`。

fixed项已包含64通道共享输入的协方差 `min(p_i,p_j)-p_i*p_j`。新增权重项非负，带符号贡献相抵不会自动抵消这项方差。此结论针对固定相同输入的一层，不能把不同整网轨迹套同一个倍率。

单个乘积的双流/固定W方差比为 `(1-pA*pW)/(pW*(1-pA))`。例如pA=0.05、pW=0.1时约10.47倍；pZ=0.008、pW=0.1、T256时平均仅0.2048个AND事件，计数为0的概率约81.47%。**pW=0.1仅为说明性假设，尚未测全模型权重概率均值。**

## 现有诊断实际支持什么

全部24层与3seed等权平均，精确双流T4096的x平均概率5.3492%，z平均概率0.8255%；各层z均值0.5361%至1.3124%。T256的上游轨迹已经改变，不能将fixed/dual的概率差直接解释为单个编码因子的因果作用。

双流T256各层最大z裁剪比例约0.000964%，T4096约0.001767%。当前证据不支持把崩溃主要归因于大面积裁剪饱和。x/z重编码NMSE是相对已带噪输入的量化误差，不是对BF16 teacher的总误差。

精确二项T256短片段PPL55019.2，而同片段固定W为40.8736、BF16为14.3291；严重退化无法全部归因于Gaussian压缩。SwiGLU、下游投影和24层传播可能把局部噪声变为偏差并放大，但gate/up与down谁主导尚无逐投影消融。

## DS-CIM并非当前数值实现的复现

| 比较点 | 当前实验 | DS-CIM原文 |
|---|---|---|
| 有符号编码 | 幅度概率加独立符号 | x,w各加128；随机主乘积再做精确offset修正 |
| 数制与范围 | 校准后固定Sx/Sz、块W8 | FP8量化后以128粒度对齐INT8；实现细节未充分公开 |
| 采样点 | 理想IID，未选择序列 | 搜索PRNG类型与初始种子，优化64/128/256点覆盖 |
| 跨行相关性 | A共享64，W每连接独立 | 双轴跨行共享及SRR区域互斥 |
| 空间归约 | 精确计数，无OR碰撞 | OR16/64，SRR消除碰撞，伴随右移量化 |
| LLM评估 | 24FFN的精确短片段PPL；旧全量双流是Gaussian | T256误差pattern注入MAC输出，六个任务准确率；无WT2 PPL |

DS-CIM Table II的FP8平均准确率66.0%，DS-CIM1为62.6%、DS-CIM2为58.8%，下降3.4/7.2个百分点，不是无损。原文未提供完整逐模块替换表和条件误差注入代码，不能断言它逐连接模拟了全部FFN或全部矩阵。[原文III-B、IV-B/C、V-B及Table II](https://arxiv.org/html/2601.06724v1)。

互斥逻辑可接受自然随机点；论文优化种子的有限T误差不等于自然IID可自动达到的误差。当前已准确归约，SRR不会凭空消除已有的权重采样噪声。offset使零附近概率增大，也需减去大修正项，不能仅凭事件更多就断言最终噪声更小。

## 其他论文的证据边界

ASTRA在OPT-350报告BLEU18.07(FP32)→17.79(INT8)→17.49(INT8+SC)，但使用确定性TCU及位位置相关编码，不是128次自然IID双流；没有WT2 PPL。[作者原文3.1及Table3](https://api.mountainscholar.org/server/api/core/bitstreams/5393ef9a-acdf-4548-a718-f05f5df3e3f9/content)。

此前真实MTJ随机源的MNIST/FIR研究支持算术与特定PPA优势，不能据此保证冻结自回归LLM的全部FFN容忍相同短流。也不能拿BLEU/选择题准确率直接换算PPL。
