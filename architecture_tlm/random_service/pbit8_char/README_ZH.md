旧37962470的独立64路比较器用P=12（W=8是权重位宽），不是本包8位随机数比较器。旧Chimera代码中输出比较和tanh表宽度为16；共享数字p-bit后端整片PT也不能拆成当前8位LUT的功耗。本次没有找到与当前signed8→q/256合同一致的独立比较器/LUT PPA。

物理层最新采样读出已验证功能，但没有保存完整电源电流瞬态。此前64×64核心、每行一个比较器约4.7145mW的数值，是核心及连续比较器DC工作点复制的预算；不含采样锁存、MUX、时钟/参考分发，也不是实际共享阵列平均功耗。不能与上表合并后称为完整随机系统实测。

## 数值和时序合同

- `pbit_compare8_lt`：8位无符号随机字r、8位q，输出 `r<q`，均匀r下P=q/256，只能到255/256。
- `pbit_compare8_q256`：r仍为8位，q为9位0..256，增加p=1端点。257..511明确饱和到1；合法接口仍限定0..256。不是改成分母255，也不是旧16位的 `<=` 编码。
- `pbit_sigmoid8_lut`：signed8输入c∈[-128,127]，实际log-odds x=c/8，q=⌊256σ(x)+0.5⌋；256×9逻辑表，与当前TLM `SigmoidTable(.125)` 全部256个码相同。c=0给128，两侧尾部会量化到0/256。**表大小是逻辑容量，case ROM综合可成为组合门，不按2304个DFF估面积。**
- 若Ising定义P=(1+tanh(h))/2，应在上游形成x=2h；不得把σ(h)当作同一曲线。β、偏置、真实g→signed8的缩放/RNE/饱和均在上游，本包不含其硬件成本，也不继承模型质量结论。
- `pbit_sigmoid8_reg`：组合表加9位输出寄存器及valid，输入en被上升沿采纳后输出；en=0保持q，valid=0。可先配置概率、后续反复比较，LUT查询次数和采样次数分别收费。
- `pbit_sample8_reg`：组合表＋端点比较＋1位结果寄存器及valid，每个en上升沿采样，同拍输入r和c对齐。无ready/反压；接入服务需保证下游有空间且输入来自同一次有效事务。新输入须满足时钟建立/保持约束。
- 两个寄存模块均低有效异步复位；没有片上PRNG、种子链、配置FIFO、MAC或完整Ising更新。r来自外部随机服务；LUT是确定性函数，不生成熵。**en是寄存器使能，不是ICG；没有承诺idle零功耗。**

## 本地功能与活动仿真

需要Python≥3.8、Icarus Verilog。解压后：

```sh
python run.py --out results/rtl_01
```

Windows便携Icarus可用 `--iverilog /path/bin/iverilog.exe --vvp /path/bin/vvp.exe --ivl-dir /path/lib/ivl`。输出目录必须不存在，保留每次失败原件。`generate_lut.py`仅用于重建冻结表，仿真会检查生成字节与已交付表一致。

验证含131072个比较输入组合（含q>256的防御行为）、256地址80位Decimal参考、65536个LUT×随机字枚举；五个top×三seed(17/503/1009)×五模式，共75案例、307200计量拍。检查复位、数据保持、valid、恢复、每笔输出和窗口计数。源码在仓库内时还检查与现有TLM表一致；独立ZIP会明确标记未导入服务模块。

| 模式 | 输入活动 | 4096拍中的有效调用 |
|---|---|---:|
| idle | 所有数据稳定、时钟运行 | 0 |
| fixed50 | q=128、c=0，只有r每拍变化 | 4096 |
| random | r、q、c每拍各自更新，合成均匀激励 | 4096 |
| sweep | q及c遍历；r更新 | 4096 |
| cadence64 | 每64拍更新一次，其余保持全部数据 | 64 |

固定c时LUT输出恒定，是概率配置后重复采样的活动例，不可用它代表每拍变化的LUT。cadence64包含输入保持假设；若真实上游在en=0时仍翻转，组合LUT仍耗电，需要另跑该负载。外部激励的Python MT19937不在DUT内，不算物理随机质量验证。

## 用户工艺库仿真步骤

`eda/synth_dc.tcl`、`eda/power_pt.tcl`是待用户在实际工具版本验证的模板，本地没有执行许可EDA。环境变量不内置工艺库/账户/远端路径。

1. **每个top单独综合**。设置PKG（本包绝对路径）、TOP、TARGET_DB（库文件的Tcl列表）、PERIOD_NS。首轮建议100MHz，之后300/500MHz分别综合和STA；时间/电容单位须从libraries.rpt确认ns/pF，负载默认0.001pF、输入transition0.1ns、setup uncertainty=20%周期。组合top使用虚拟时钟，寄存top使用真实时钟；不把纯比较器额外加上测量DFF。检查链接、黑盒、latch及面积报告。

```sh
dc_shell -f "$PKG/eda/synth_dc.tcl" > dc.log 2>&1
python "$PKG/run.py" --vectors-only --mode random --seed 17 --out gate_random_17
```

2. **用mapped.v而不是RTL重新仿真**。在新活动目录编译工艺Verilog模型、mapped.v、`tb/tb_activity.sv`；不要同时编译RTL，否则会重定义模块。CASE=0/1/2/3/4依次对应上面的五个TOP。例如100MHz的采样端：

```sh
vcs -full64 -sverilog +define+CASE=4 -pvalue+tb_activity.PERIOD=10.0 \
  /path/to/standard_cells.v /path/to/mapped.v "$PKG/tb/tb_activity.sv" \
  -top tb_activity -o simv
./simv > gate.log 2>&1
```

其他频率必须同时改PERIOD_NS与TB.PERIOD；300MHz采用同一可表达的ps周期并记录有效频率。切勿只改综合约束。此模板零延迟门级、独立STA，无SDF毛刺/CTS/SPEF，不能当后布局签核。若加入SDF，需相应处理驱动和检查时刻并重新验证，不关timing check掩盖错误。

3. 检查gate.log中的ACTIVITY_PASS和零错误，按其start_ns/end_ns取**测量窗口**，排除复位/16拍预热/末尾恢复。保留mapped.v、向量、库版本、VCD、日志SHA。VCD只dump `tb_activity.c.dut`，用PT同名strip_path。生成活动覆盖/未注释报告，检查所有实际库引脚的X/Z及反标；不能仅因输出正确或文件存在就判功耗活动有效。

4. 设置TOP、TARGET_DB、NETLIST、SDC、VCD、START_NS、END_NS、GATE_LOG，再执行 `pt_shell -f "$PKG/eda/power_pt.tcl"`。该模板仅检查功能日志入口，**不自动证明VCD来源、全引脚覆盖、无X/Z或库单位正确**；这些必须连同库表告警、setup/hold人工或沿用已有严格PPA流程审核。不能拿本包RTL VCD直接报门级功耗。idle可能没有动作，pJ/op应留空。

5. 每个top三seed分别记录内部/切换/泄漏/总功率及面积；单位明确后 E_window[pJ]=P[µW]×窗口[ns]/1000，E_op=E_window/调用数。组合比较/LUT按输入被评估次数定义调用，寄存模块按en；idle另列。总能量和减去idle的增量能量分别报告，不能互相叠加。查表、比较器分别测的能量只作模块预算；融合采样端可能综合优化，不能假定恰好相加。

## 阵列和TLM回填边界

FFN输入已经是概率码时只调用比较器。真实g的sigmoid分支才调用查表；同一个q保持64次采样时，是1次查表、64次比较、64次取随机字，不能按64次查表计。表输出寄存器若已在消费者计入，不可再次加账。

当前TLM描述16查询/拍，可先测本包单路LUT，再给预算范围；最终还需16路物理复制/共享调度及扇出负载版本验证。64比较器若共享同一个随机字，输出之间通常相关；广播可以摊省随机字生成，但不变成64份独立熵。这里的五个核不替代多路布线、仲裁、概率存储与完整FFN端口表征。

疑点和待验证：500MHz组合LUT→比较路径能否通过；复制16路的布线/扇出；真实g转换边界；低频配置时的输入隔离和真正ICG；实际模型分布活动；物理读出全电源瞬态。上述均未用估计填成已测结果。收到结果后，在同一Issue95和统一数字仿真台账登记实际DC/STA/PT阶段。
