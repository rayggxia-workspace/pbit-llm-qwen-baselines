# 100 MHz SRAM缩减与带宽回放

2026-11-07，Issue225 / PR248，rayggxia。当前默认改为 **1088 KiB、272个4 KiB bank**，保留1056 KiB更小容量候选。250 MHz的960 KiB默认与3核配置不改。

| 配置 | 前端/Attention bank | 冷单层时间 | 覆盖面积估算 |
|---|---:|---:|---:|
| 原1216 KiB | 176 / 128 | 1.207620 ms | 34.14593 mm² |
| 仅删除DMA预留，1184 KiB | 168 / 128 | 1.245500 ms | 33.93063 mm² |
| 最紧凑1056 KiB | 168 / 96 | 1.244230 ms | 33.06940 mm² |
| **当前1088 KiB，保持供数带宽** | **176 / 96** | **1.206150 ms** | **33.28471 mm²** |

两轮分别同源配对；第一轮提交89bb0b9f验证三个容量，第二轮c2d860f6验证原1216和1088保持带宽版。两次原1216时间完全相同；保留第一轮负面结果和全部原始字节。

## 改了什么

- 八组Attention缓冲各64→48 KiB，减少128 KiB/32个bank。V缓存仍128项，K128/S64与全部算术/采样量不变。
- **删除旧32 KiB DMA SRAM逻辑区域**，返回数据仍由16 KiB有限寄存器保持；256请求信用、回压和每通道返回端口不变。
- 100 MHz特有的1 KiB QK转置双缓冲，从每组48～49 KiB搬至34～35 KiB；选中K占0～32 KiB，分数占32～34 KiB，输出改为47～48 KiB。粗筛分数在转置前已消费；128 B转置暂存寄存器保留并计价。
- 普通投影两槽仍各80 KiB，实际tile会用满；FFN6核、GU16/Wd32、CIM权重256 KiB、跨K状态96 KiB、640 FMA/128 PV ADD/32归约及10 KiB投影FIFO均保持。

## 为什么默认不是1056 KiB

删除旧32 KiB区域后，如果也删除其对应8个前端bank，前端只剩168个16B/1RW端口。100 MHz数字投影需同时回填权重和读取操作数，bank冲突增多：QKV的FIFO数据等待11.64→26.04 µs，O为7.69→17.46 µs，完整冷单层约慢3.03%。这些等待来自实际端口仲裁，不是加上的固定惩罚。

因此当前1088版保留176个前端bank，Attention缩至96个bank。**逻辑对象合计1056 KiB，物理容量1088 KiB，多出的32 KiB是分散在前端bank中的容量余量，用来保留端口数**，不是恢复DMA缓存或免费端口。所有272个宏都计入面积和漏电。此布局投影供数恢复，时间相对原版−0.122%，视为持平；覆盖面积少0.86122 mm²，约2.52%。

1056版仍可通过显式参数选择，换取额外约0.21531 mm²面积；没有删除其较慢结果。后续可独立研究bank映射或更小宏组织，本轮不假定有未标定的便宜端口。

## 验证及范围

四项新检查与八项旧SRAM检查通过：真实bank/物理行唯一、所有对象有界、不同生命周期数据图样保持、非法活跃重叠拒绝、实际12-bank服务、完整151936词表投影tile覆盖。主配对全部算术/采样动作、6080 GU/3040 Wd帧、外存各类字节与地址sum/xor一致，输入及执行源SHA相同；队列/信用排空。不是只改面积表。

回放是解析136.4606 GB/s、30 ns外存，片上10 ns真实bank/队列/信用；完整冷第0层含embedding、不含lm_head，按36层分配地址。全词表只检查tile容量与覆盖，本轮未跑完整原生LPDDR token、GPU/PPL或新RTL/PT。

面积按原SS100校准与已测C19核价，仅替换真实SRAM宏个数；原始宏面积×0.81一次，不缩放功耗/周期。SRAM事件动态和漏电按各回放统计，核池按活动gross＋停钟等待计算。其他成本仍沿原模块依据，完整整芯片能量保持null；不把容量下降比例当总能量下降比例。仍不是流片die面积。

CURRENT_100MHZ.json仍指向host100.make_model，工厂默认sram_configuration='compact1088bw'；显式compact1216、compact1184、compact1056为对照。旧FFN6/采样工厂的默认1216保持，避免把历史入口悄悄改名。完整decode工厂仍支持36层/head参数。

```powershell
python -B architecture_tlm/module_refresh_20261107/test_sram100.py --project <项目根> -v

```
