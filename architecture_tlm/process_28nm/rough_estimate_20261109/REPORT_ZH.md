# Qwen3-4B：28nm整机条件初估

2026-11-09，Issue225 / PR249，rayggxia。**现在足够给出大体面积、decode时间和能耗；下面是实测模块＋小规模事务回放＋显式宏的估计，不是完整芯片签核或完成的36层原生LPDDR运行。** 严格价卡中的缺项仍为null，本报告另列条件情景，不修改55nm默认或旧封存。

## 一眼可读的结果

Qwen/Qwen3-4B，B1，2K上下文，36层；W8随机FFN，GU16次、非线性-Wd32次；SparQ K128、Ising/PV S64；QKVO和lm_head为BF16数字池。片上960KiB/240个4KiB bank、16KiB返回保持、256 FMA；外存维持136.4606 GB/s、30ns解析后端。250MHz三FFN核，500MHz两核，比较的是这两种候选配置。

解析后端不能代替新一轮原生LPDDR回放。参照已有55nm冷单层原生/解析差异，额外给0–12%时间敏感性：含head约46–51ms、41–46ms；这不是经验证误差界。保留原生存储细节后再收紧范围。

## 时间来自哪里

没有把55nm总时间按工艺或频率直接缩放。使用已通过SEAL的28nm有限bank/DMA回放：250MHz两层及384词条head；500MHz单层。按相同层形状投影36层，首层冷启动与稳态分开，embedding/最终norm只计一次。500MHz当前只有一个层样本，稳态依据弱于250MHz。

新增六个真正运行的小型head探针：两个频率各1024/1152/2048词条。head采用同一个256FMA池、8包有限操作数FIFO、两个权重槽、bank仲裁与DMA等待。用1024→2048拟合256词条的稳态增量，用1152测128尾块，外推593个完整256块＋128尾块=151936词表。实际没有跑完整151936-head；拟合负的微小截距只是流水线拟合项，不是负启动时间。

单位mm²。实例面积只按物理资源计一次，未乘36层。28nm面积系数为1；55nm旧SRAM校准锚的原始面积按用户规则乘0.81一次，未对28nm再次折算。

新CACTI作业38638027已COMPLETED，双结果及SHA校验通过：28nm、300K、4KiB、128bit、1RW，单bank面积0.00552094mm²、访问0.735862ns、最小周期0.580697ns、读1.80924pJ、写4.75195pJ。240bank原始CACTI面积1.3250mm²。中心估计进一步把同组织55nm宏E相对55nm CACTI的残差比值迁移到28nm，得到1.6735mm²；**这不是28nm工艺库校准**，28/55电压等差异也不因此消失。

PV保留每头128个FP32状态、反馈/读出等固定寄存器；只对剩余组合逻辑按2/16作代理缩减，没有将整个16ADD wrapper面积除8。范围高端保留整个wrapper成本。DMA/FIFO采用实际28nm寄存器单元平均面积，容量和描述符假设单列。范围同时变化SRAM残差、PV、存储/控制预留、500FMA及布局比例，不是统计置信区间。

## 还需确认的三件事

1. 28nm SRAM库或宏表征，以及500MHz共享数字FMA的真实流水/吞吐。CACTI的2ns以内访问只支持可行性分析，不保证bank wrapper/互连也满足2ns。
2. 紧凑PV、DMA/FIFO/向量及CIM接口的28nm成本。当前PV数据setup失败，500FMA用了同工艺250价代理，均未冒充严格合格模块。Ising仍是已测平均服务宏＋封存地址流，不是逐query28nm动态轨迹。
3. 完整36层＋完整词表的原生LPDDR回放，保留长程预取/排队。当前是小回放外推，没有新增PPL或质量主张。
