# 128拍是什么、DS-CIM为何不同、当前基线应如何理解

2026-10-18，Issue19 / PR20，负责人@jieruiz。接续本任务精度分析；DS-CIM的存储/工艺专题仍归Issue5 / PR6，本次不覆盖其实现或接管其分支。

## 结论

128是采样拍数，不是128位数值精度。本次仍编码A8幅度加独立符号；128拍分层是带随机舍入的unary计算，可以归在广义随机计算/混合确定与随机计算中，但不能称为每拍独立的Bernoulli计算，更不是已经验证的物理tanh p-bit网络。

当前没有发现分层计数、符号或尺度恢复的明显程序错误；存在更实际的架构和比较问题：固定尺度下许多小概率、共享导致的相关误差、非线性传播，以及尚未完整复现DS-CIM的联合采样和区域重映射。4096拍是旧IID参考，不是随机计算的必然要求。

DS-CIM也没有证明64拍LLM几乎无损：其LLaMA-7B实验用256拍误差模式注入，六任务平均准确率从FP8的66.0%降到62.6%或58.8%。最高能效、最短流和最高精度是不同配置，必须分开。

## 128拍的随机性具体在哪里

输入幅度码q在0～255，目标概率p=q/256。将256个门限分成128个区间，每区间两个整数，随机取其中一个。完整128拍的计数满足：

```
q为偶数：C = q/2
q为奇数：C = (q-1)/2 或 (q+1)/2，各一半
恢复概率 = C/128
恢复到原A8码单位 = 2C
```

例如q=100始终恢复100；q=101随机恢复100或102，均值101。这是无偏随机舍入，随机性只影响边界区间；其他区间的输出已确定。64路共享中，同组相同q共用这个边界随机位，不同边界区间的jitter各自独立，不是整组只有一次投币，也不是逐元素完全独立。

输出计数可以是0～128，因此也不能直接把它称为完全相同的普通7位无符号编码。真实电路可用计数器高位加随机低位驱动原比较器；本次PPL用保持联合分布的计数压缩，不是具体LFSR逐拍仿真。

若固定每区间中点，T128的严格比较器给C=floor(q/2)，是确定性向零截位。完整enum256则令C=q，完全等于同一A8量化线性矩阵。固定权重与精确累加使流的时间顺序不影响最终线性结果；双随机流AND和在线非线性不能直接套用这一结论。

所以这组基线应该保留，标签应明确为IID、随机分层、确定性midpoint、完整枚举，后续再与RNE低位量化及位串行比较；不能仅凭“仍有随机性”就主张值得做成128拍电路。

## DS-CIM实际做了什么

原文：Shao等，DATE2026，*DS-CIM: Digital Stochastic Computing-In-Memory Featuring Accurate OR-Accumulation via Sample Region Remapping for Edge AI Models*。[公开原文](https://arxiv.org/html/2601.06724v1)。已逐页提取用户7页PDF，并目视核对p3～p6的Fig.2、4～7和Table I～III。用户PDF SHA-256：`6f736516b0534d81e3c0a08eb3822674b827c344e8051353a02ebfeab6ef9aef`。未将受许可PDF上传仓库。

| 环节 | DS-CIM原文事实 | 我们目前方案/差别 |
|---|---|---|
| 操作数 | 激活和权重都经SNG转为比特流；两套独立PRNG提供A/W坐标，跨行共享。§III-A，p2 | 本次是固定多位W、仅x/z随机。旧双流实验也没有自动包含下述全部机制。 |
| 符号 | 补码翻转符号位，x'=x+128、w'=w+128，计算无符号乘积后用输入和/权重和修正。Eq.2～4，p2 | 我们采用abs+sign。偏移编码改变事件分布，也引入修正和相减；不能断言仅换偏移编码必然减噪。 |
| OR累加 | 共享二维采样点，预先右移、变换数据与比较方向，使同组乘积事件互斥。§IV-B/Fig.6，p4～5 | 普通OR2/4或独立双流不是其SRR复现。当前G1精确累加本来没有OR碰撞，不能指望SRR修复所有采样噪声。 |
| 截位代价 | OR4的A/W各右移1位；OR16各右移2位、4×4分区；OR64各右移3位、8×8分区。§IV-B，p4～5 | 消除碰撞以低位精度为代价，不是保持原INT8全部乘积信息；恢复尺度、边界和符号修正仍须完整实现。 |
| 短流精度 | 搜索主流8位PRNG及A/W初始值，为64/128/256点降低二维点集discrepancy。§IV-C，p5 | 我们本次IID是理想有放回抽样；分层是一维有序分层，不是同一套二维优化点集。 |
| 量化 | LLaMA用LLM-FP4框架做FP8，再按128粒度对齐到INT8。§V，p5 | 我们是每64组固定Sx/Sz、W按64×64tile，量化不是同协议。这里的128粒度不是128拍。 |
| 模型评测 | 将DS-CIM误差模式加入MVM/MAC输出；LLaMA明确用256拍。§V/V-B，p5～6 | 我们在FFN线性入口采样联合事件计数，非线性随实际扰动传播；也未完整运行逐边DS-CIM电路。两者误差相关性不宜预设相同。 |
| 训练 | Table III写明不需要重新训练，p6 | 不能把论文精度解释为靠重新训练；其量化校准与序列配置优化仍然存在。 |
| 吞吐 | CMR=64复制低成本OR-MAC，共享存储/W-SNG，增加并行计算上下文。§III-C/Fig.4～5，p3 | 不是单条256样本流压缩成4样本。原文也指出256拍比8拍bit-serial主体慢32倍，靠并行度/面积摊销补偿。 |

Fig.6的直观解释：把每一项A×W看作二维平面中的一个矩形。普通AND判定一个采样点是否落进矩形；多个矩形重叠时，OR把多个命中误算为一个。SRR先缩小矩形，再安排到互不重叠的小区域，一个点最多命中一项，OR才等同这一拍的加法。**它修复OR碰撞；有限采样误差与右移误差仍然存在。**

原文用40nm定制SNG/OR-MAC单元、综合布局布线与后仿真；不是原型芯片的LLM整机实测。缓存累加、SRAM复用、CMR并行度影响能效和吞吐；它们本身不等于提高单条采样估计精度。不能把“最高效率”与“最好准确率”拼成一个配置。

公开7页原文没有充分给出最佳PRNG型号/全部种子序列、RMSE归一化定义、逐层误差注入和相关性细节，也未报告LLM三种子PPL；这里不能凭表格反推出同等精度的逐拍实现。没有据此判断其结论错误，也没有声称已经独立复现论文。

## 我们到底哪里需要改进

1. **先前4096不是必要下界。** 对本次固定W、固定A8输入、精确空间/时间累加，256门限完整遍历已精确。它不能证明通用双流乘法256拍精确：例如两路1/256概率的乘积是1/65536；两边各遍历一次也不保证联合分布。
2. **固定尺度与短流事件幅度。** 当前无采样z平均p约0.00631，64拍平均仅约0.404个事件；q=1在64分层恢复为0或4，在128分层恢复为0或2。大固定Sz和极值校准是主要疑点，应试分组/裁剪校准等控制；不是只增加随机源数量。
3. **随机矩阵无偏不代表整个FFN无偏。** 同一含噪x共同驱动g与u，经过SiLU(g)u后，曲率与协方差都可能产生偏差；层层累积。需要gate/up-only、down-only消融才能定位，不能从单个零事件率推出全部因果。
4. **共享需要可控相关性。** share64节省随机源，但同组相同码会同涨同落。应在相同尺度/采样预算下比较共享粒度或不同投影的序列配对；并非共享一定差，也不能假定永远免费。
5. **确定性对照还不够强。** midpoint128是截位，需要补RNE及合理缩放的低位量化；有序帧末线性结果可用随机舍入后短位码运算得到，128拍未必是最省电的物理实现。合理bit-serial和INT8 MAC必须保留。
6. **旧双流/OR结果是探索，不是DS-CIM复现。** 需要明确版本的偏移编码、符号修正、SRR、二维点集、量化、累加位宽和输出尺度，不能只把两个输入变随机就用论文名称。

256枚举与确定性Q10的完整总NLL相同，以及小矩阵逐拍/整数对照测试，支持本次未发现明显恢复错误；它们不能代替对实际PRNG、有限位溢出/重缩放、DS-CIM电路的验证。服务器已有18/18数值/CUDA测试记录；本次文档审计未重新训练，也未做新的芯片能耗测量。

## 建议的下一步顺序

先保留并合并这组可复现基线，原数组2084继续，不重写执行快照。随后优先补投影消融、RNE和尺度对照，再验证二维低差异/优化PRNG的双流精确计数，以分开“采样不好”和“OR碰撞”。最后才在同一数制上增加OR4/16 SRR及完整符号修正，既测数值误差也测完整PPL。

若短流没有优于确定性低位运算，应接受固定矩阵采用数字/位串行计算，p-bit用于更匹配的概率非线性或Ising模块。论文价值来自同精度、同硬件边界的比较，不来自一定保持全随机。
