## 整机模型怎么接，不需要重做什么

沿用55nm现有的分bank SRAM、本地缓冲、有限DMA信用、预取、部分和更新及PV生产消费执行框架；重新绑定28nm的服务周期和价格，而不是把旧总时间除2、面积等比缩小。LPDDR模型独立复用。最初可保留250版960KiB/240bank、16KiB返回保持等拓扑作候选，不预先把500MHz的核数/SRAM减半，也不声称它们是最优。

下一步关键只分三组：

1. **存储/公共服务**：给SRAM宏容量、端口、读写周期、面积/读写能量/漏电；DMA/FIFO和通用向量操作可先用显式宏。SRAM先用CACTI估算或库数据皆可，不要求每一形状先PT。500MHz必须说明SRAM能否2ns服务，或显式模拟独立存储时钟/流水。
2. **仍在收尾的模块**：更新PV合格价、共享BF16新流水/上下文及数字FFN。新仿真能量/面积通常只替换价卡；若latency、II、端口或状态大小变了，才重做对应阶段调度。
3. **宿主回放**：把绑定挂入原有限存储调度器，先完整形状冷单层，查工作量/实际读写/credit/时钟，再做完整36层＋head。250先扫描2/3FFN核，500先扫描1/2核；数字池先保留原候选后测，不仅按峰值频率决定核数。

允许先做带明确宏假设的条件整机估算，再等补测替换确认；`full_system_ready=false`只是当前尚未完成整机回放与PPA覆盖，不是禁止继续搭模型。未绑定项目必须逐项给假设或保留未知，不得因Python允许计算就免费使用理想算子。本轮整机时间/总面积/总能量仍null。
