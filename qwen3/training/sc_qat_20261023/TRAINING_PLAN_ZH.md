# Qwen3-4B：多档随机FFN的全模型训练与扫描方案

2026-10-23；负责人：jieruiz。**目标模型严格为 `Qwen/Qwen3-4B`，不用 Base，也不自动换成 Instruct-2507。** 本文件是训练设计和待执行清单，尚未实现训练器、运行新模型基线或提交H200作业。机器清单见同目录 `SCAN_MANIFEST.json`；校验器不是训练器。

## 1. 建议先做什么

采用**全参数量化＋随机运算感知微调**：从原始Qwen3-4B初始化学生，保留一份原始BF16模型作冻结教师。学生36层FFN都采用W8、分档输入和真实随机采样；用整个语言模型的损失联合更新。Attention先沿用准确算法，参数可以随全模型一起调整。

训练最值得回答三个问题：

1. 动态尺度下，32次采样能否降到16次，甚至8次？
2. 完全静态尺度能否达到动态尺度的质量，从而去掉在线求最大值？
3. 难点是否主要在SwiGLU输出 `z`，是否值得给down投影更多档位或采样？

**W8指前向和导出权重为8位，并不表示训练时冻结权重。** 保留浮点主权重，通过代理梯度更新；前向每次重新得到W8。部署时权重才固定存入SRAM。算力充足时优先全参数训练，LoRA不作为第一版主方案。

## 3. FFN前向必须和目标电路一致

```text
RMSNorm后的x
  → 按64通道一组选择尺度档 → A8概率码、符号 → T_x次采样
  → 同一份x采样同时驱动Wg/Wu（两个W8矩阵）→ g、u
  → 连续计算SiLU(g) × u → z
  → z用自己的尺度档、独立随机流，采样T_z次
  → Wd（W8）→ 恢复并转回BF16 → 残差相加
```

第一版保持PR147算术：三矩阵按64×64 tile对称W8量化，码值−127…127；输入为带独立符号的A8幅度概率，`p=q/256`，概率1用单独满幅旁路，不能以255/256代替。FFN恢复、矩阵数值参考及SiLU/乘积先保持FP32，接口BF16；非FFN部分按匹配BF16模型执行。若后续用BF16 GEMM提速，必须另做匹配性检查并标为新的数值后端。

64路共享门限、跨尺度档共享门限；gate/up共用同一次x采样，z独立。不同token、通道组、层、阶段使用不同随机流。这些相关性必须进入训练，不能用独立高斯噪声或每通道独立Binomial取代。

每组B档为 `S, S/2^d, …, S/2^(d(B−1))`。每个元素选择能容纳其绝对值的最小档；小于最低档仍使用最低档，超过最高档截断。**静态只是不再在线算组最大值，不等于没有逐元素档位比较、编码或截断。** 分组沿原通道顺序，不需要把大小值重排聚类。

| 尺度方式 | 训练与推理的行为 | 在线组最大值 |
|---|---|---|
| D：动态x＋动态z | 每token/64通道算最大值，再向上取2的幂为S；各档按固定间距生成 | 两处都有 |
| F：固定x＋固定z | 训练集离线校准，每层每组S固定；权重适应该表，训练/测试均不更新表 | 无 |
| L：可学习静态x＋z | 每组学习log2(S)，前向始终投影到整数指数；最后20%训练冻结，部署只读固定表 | 无 |
| H：固定x＋动态z | x使用离线表；z仍动态，作为低成本前端的折中对照 | 仅z有 |

Qwen3-4B每层x有40组、z有152组，36层合计6912组。若每组只保存一个8位顶档指数、其余档由公共d生成，逻辑尺度元数据为6912字节（6.75KiB）；这不含权重量化尺度，也不是SRAM物理面积。各组尺度不同不等于使用BF16矩阵乘法：归约仍需按档整数累计、最后按2的幂恢复。

## 4. 简单扫描清单

先固定W8、A8、组宽64、共享64、所有36层、准确Attention，不把所有变量一次做笛卡尔积。

| 参数 | 第一轮/后续候选 | 默认 |
|---|---|---|
| 尺度策略 | D、F、L、H | 四种都测 |
| 每阶段采样T | 8、16、32、64；128仅作低噪声评估锚点 | 32 |
| 档数B | 2、4、8；1档可选负对照 | 4 |
| 相邻尺度比 | 2、4、8，即d=1、2、3 | 4，即d=2 |
| x/z采样预算 | 先相同；再测(8,16)、(16,32)、(32,64) | (32,32) |
| 随机规则 | 分层K=T；另设自然IID K=1匹配训练对照 | K=T |
| 固定尺度顶档 | 首轮用训练校准最大值向上取PoT；再试99.9/99.99/99.999百分位 | max，无额外headroom |
| 优化超参数 | 最终候选再扫FFN LR=3e−6/1e−5/3e−5，蒸馏λ=0/0.5/1，逐项扫描 | 1e−5、λ=0.5 |

例如B4/d2是 `[S,S/4,S/16,S/64]`；B4/d1是 `[S,S/2,S/4,S/8]`。**B=档位数，K=随机门限分层数，T=采样总次数；三者不是同一个量。** T32/K32表示256个门限值分成32区，每区随机取一个8位门限；自然IID则每拍独立从0…255抽取。即使使用物理随机源，分层仍需区间映射/控制，不能省略成本或称为无约束IID。

实际分阶段安排：

| 阶段 | 配置数和预算 | 要作出的决定 |
|---|---|---|
| 0：实现与校准 | tiny模块/小模型、真实4B短步、100–200步profile；训练数据单独取约2M tokens校准、1M holdout诊断 | 排除梯度、模板、重放错误；重做非Base BF16/W8/未训练随机对照 |
| A：主扫描 | **4策略×4采样=16组**，每组约200M有效训练token，同数据顺序、同训练seed；另3个控制，共19组 | 找动态与全静态各自最佳质量/预算点 |
| B：档位扫描 | 最佳动态与最佳全静态各B∈{2,4,8}、d∈{1,2,3}，**最多18组**；同预算且配置完全相同时复用A结果 | 确定档数、间距，避免只凭占档图选优 |
| C：针对性检查 | 对入围结构逐项测x/z不等T、z8档、固定顶档百分位；自然IID对照至少覆盖两结构×T16/32/64 | 判断z是否值得更多资源，以及收益是否依赖分层 |
| D：最终训练 | 选2–4结构，每种2B有效训练tokens起；曲线未收敛再扩到5B；最终优选至少3个训练seed | 导出真实W8和冻结尺度，做完整任务评测 |

A中三个额外训练控制：相同数据/预算的BF16微调、W8-only QAT、固定B4/d2的A8编码期望值QAT（无有限采样噪声）。另保存原始未训练BF16和相应未训练随机模型用于因果比较。B/C不是混在一个大网格里盲扫，使用独立验证集排序；200M只是筛选预算，不能把短训排序当最终收敛排序。

机器清单明确列出19个A阶段计划，不是已经完成的实验。B/C阶段继承验证集选中的结构与校准设置，保存父checkpoint/config SHA作为选择证据，仍从同一原始模型独立训练同等预算；若另做续训，必须计入累计token并提供匹配续训控制。不能用WT2测试集反复选择最佳档位/尺度。

## 5. 具体怎样训练

### 5.1 数据与损失

冻结原始**非Base Qwen3-4B**教师。学生对同一token序列进行带噪前向，最初使用

`总损失 = 下一个token交叉熵 + 0.5 × KL(教师分布 || 学生分布)`，蒸馏温度先用1。

建议起始数据比例按有效监督token计：**40%通用文本/代码/多语言，30%非思考指令/多轮对话，30%思考类数学/代码/推理**。这是待验证的工程起点，并非官方训练配比。使用有许可、去重且去除评测污染的训练数据；执行前补齐来源、版本、split、混合权重及SHA。只用WT2训练集重复训练数十亿token不能证明保留整体能力。

原始文本计算next-token损失；对话只对assistant目标计分，覆盖目标轮次需要保留的推理和最终回答。保存并核验官方chat template；`enable_thinking`不替代对最终渲染token和loss mask的检查，防止双重think前缀、误删当前答案推理、或只保留长推理前半段。训练、教师和评测的模式必须一致。校准样本覆盖prefill、普通回答和长推理decode。

首轮序列4096；最终候选按token约50% 4K、30% 8K、20% 16K继续训练，视数据长度调整。超长样本保留完整最终答案，不把任意截断样本当完整推理；32K能力单独评估。通用PPL和对话任务分开记录。

### 5.2 权重、采样和尺度的反向传播

保留可训练主权重，前向得到 `W8_fake = W + stop_gradient(dequant(quant8(W)) − W)`，得到真实W8数值、以STE回传梯度。tile尺度首版按当前主权重max计算并停止尺度梯度，导出时固定；不能继续沿用只含冻结buffer的推理类。

随机输入的前向必须是真的计数 `C/T`。反向用显式声明的有偏代理梯度；它不是精确无偏随机梯度。固定/动态尺度版可以先对截断范围内传递单位梯度，范围外为0。对可学习静态尺度，不能把整条尺度路径detach后声称尺度已训练；推荐按下述计算图实现并单独验证：

```text
e_ST = a + stop(round(a) − a)              # a为每组可学习log2尺度
S = 2 ** e_ST                             # 前向始终为PoT
档位选择停止梯度，但所选档尺度保留对S的梯度
p = clamp(abs(x)/所选档尺度, 0, 1)
p_q = p + stop(A8概率量化(p) − p)
p_hat = p_q + stop(真实共享采样计数/T − p_q)
x_hat = sign(x) × 所选档尺度 × p_hat
```

零输入处的符号/绝对值梯度需显式约定，避免意外NaN；尺度梯度归一化可借鉴LSQ。依据校准范围确定并记录合法指数上下界，确保最高档不溢出、最低档不下溢，监测触界率，不能无记录扩大范围。先检查有限梯度、权重/尺度确实更新、精确前向匹配；**不能用硬量化函数的有限差分来要求STE等于真实导数**。动态尺度的absmax/取PoT/档位决策首版停止梯度。

L方案前80%训练可学习尺度、最后20%固定整数指数继续适配；部署完全冻结。F方案离线表从开始就固定，不能悄悄在线扩范围。校准仅使用TRAIN，x/z分别统计，至少覆盖W8-only和目标动态采样学生路径，不能只统计BF16教师的z。离线校准与L初始化先保留离群值，裁剪百分位放在C阶段单独检验；holdout/test不更新表。CE与KL共用有效监督mask与token归一化分母。

### 5.3 日程和默认优化器

- 所有训练配置从同一原始checkpoint初始化；控制组得到同等数据预算。
- 随机配置前5%有效token仅W8+A8期望值前向，随后15%从T128、64逐步到目标T，后80%固定目标T；每步噪声更新。K=T时随T变化，IID控制始终K=1。
- AdamW，FFN主权重LR=1e−5，其他参数LR=2.5e−6，betas=(0.9,0.95)，weight_decay=0.01，grad_clip=1，学习率warmup约3%后cosine。学习尺度可先设LR=1e−4、无weight decay；这些都是待profile/验证的起点。
- 全局每次优化更新约131072有效token；动态packing/不同监督mask时按真实有效token归一化与计预算，不能只用序列长度×batch替代。
- 同一checkpoint分别在T8/16/32/64/128推理，得到训练T与推理T的迁移表；不能假定只训64就天然适合8。

固定W＋精确线性累加允许先对输入求随机计数、然后一次GEMM，数学上等于逐拍W乘输入再累加。训练中每次前向的W视为固定，因此可用这一等效方式减少GPU开销；它不改变目标硬件T拍的含义。OR饱和或周期内非线性不能套此交换。

## 6. H200如何使用

先以**两组各4张H200并行训练，另2张做教师数据生成/评测**作为排程起点；训练组内各自运行冻结教师，不依赖跨组同步传送所有logits。先profile，若两卡足够且通信更省，可以改为更多两卡任务。按实际NVLink节点分组，不假设十张卡互联完全一致。

采用FSDP/ZeRO分片优化器状态和必要的参数，activation checkpointing。4B全参数Adam混合精度常规持久状态预算约每参数16字节、合计约64GB量级，另加教师、激活、FP32 FFN工作区等；不是因为前向W8就只需要4GB显存。不要把 `device_map="auto"` 推理切分当分布式训练配置。

全词表KL不要保存整个数据集的dense logits，可对token/词表分块计算精确归一化和KL。若改top-k蒸馏，应作为明确近似单独记录。先做100–200步实测吞吐，再按 `训练tokens/有效tokens每秒`估时间；不按H200峰值BF16算力保证工期。PR147的FP32 FFN路径可能成为训练瓶颈，后端提速需验证。

**随机重放是实现门槛。** 每步/微批次使用新随机性；activation checkpoint重算同一前向必须重放相同随机数。PyTorch全局RNG保存不能自动覆盖我们自建Generator：使用明确的run seed、step、microbatch、rank、layer、stage、token/group计数键，重算不推进状态。恢复训练保存优化器、数据游标和这些键。FFN内部采样seed与生成解码seed分离。

## 7. 以什么标准认为训练有效

先重新锁定非Base模型revision、权重/分词器/模板/语料SHA，运行同环境原BF16；不能使用Base PPL作参照。当前模型ID已确认，官方元数据直连未成功取得revision，执行前必须补锁定；本次没有下载权重。

| 层级 | 必做验证 |
|---|---|
| 训练模块 | 兼容配置与PR147旧推理oracle一致；新增d1/d3/静态等用独立逐拍参考；显式比特流与压缩计数等价；共享协方差不变；零/满幅/负数/跨档边界正确 |
| 反向与恢复 | 所有36层每个投影Parameter的梯度范数非零且optimizer后实际改变，不要求每个元素都非零；尺度L实际改变；重计算/不重计算、保存恢复的随机轨迹和loss一致 |
| 数值质量 | 完整WT2：window2048/stride1024、语料原字节与计分覆盖固定；另有独立通用验证集用于选参 |
| 通用能力 | PIQA、ARC-E/ARC-C、HellaSwag、WinoGrande，保持同一harness/模板；可先PIQA＋ARC-E做中期筛选 |
| 非Base能力 | IFEval严格指令分数；GSM8K/MATH-500思考与非思考分开；代表性代码任务；模式切换、重复、think结束、截断率、答案完整率 |
| 导出 | 真正导出W8、尺度表、配置和SHA，关闭observer；重载部署模块复测，覆盖prefill与decode全36层 |

随机推理至少3seed，最终优选至少3个训练seed；不要把3个推理seed说成3次独立训练。生成任务固定解码策略/输出预算，并与原BF16成对比较；thinking不默认改greedy。质量目标先设相对PPL增加≤1%、代表任务平均下降≤1个百分点，且没有明显模式/长生成失效，属于选型目标不是已取得结果。多个任务还应看逐任务差值与不确定性，不能用平均值掩盖某一能力崩塌。

只有同时通过质量门槛，再比较 `T_x/T_z、档数、动态max、状态与访存` 的代价。T减半只代表采样部分预算减半，不代表整机能量或时延减半；B增多也增加分类/计数等成本。最终再把优选FFN与Attention概率版本联合适配，避免第一轮两个噪声源同时变化而无法归因。

- [Analog Foundation Models](https://arxiv.org/html/2505.09663v2)：最接近的依据，结合静态输入范围、硬件噪声、教师指导适配预训练LLM。其模拟计算噪声不同于我们的共享比特流，不能直接照搬Gaussian噪声模型或声称已验证短流FFN。
- [LLM-QAT，ACL2024](https://aclanthology.org/2024.findings-acl.26.pdf)：支持从预训练教师进行量化适配与蒸馏，无需从零训练。
- [EfficientQAT，ACL2025](https://aclanthology.org/2025.acl-long.498.pdf)：局部训练与端到端尺度适配可结合；本方案全模型更新范围更广，需独立验证。
- [LSQ](https://arxiv.org/pdf/1902.08153)、[PACT](https://arxiv.org/pdf/1805.06085)：可学习量化步长/裁剪范围的基础。PoT多档、带符号x/z及共享随机采样是这里的扩展。
- [PyTorch QAT说明](https://pytorch.org/blog/quantization-aware-training/)、[checkpoint文档](https://docs.pytorch.org/docs/stable/checkpoint.html)：fake quant/STE和随机重放的实现依据；通用量化模块不能直接替代本项目采样律。

所有训练预算、学习率、数据比例和成功门槛均为建议值；本文件没有新模型PPL、任务准确率、训练吞吐或硬件PPA结果。
