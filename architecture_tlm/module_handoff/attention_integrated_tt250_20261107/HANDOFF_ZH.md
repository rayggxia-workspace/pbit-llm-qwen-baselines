# 250MHz Attention模块交接

本模块已完成独立250MHz整体估计，建议压面积候选为 **256 FMA＋64 PV ADD＋4套top/归一化＋4采样核＋16路末端归约**；偏重时延时保留320 FMA/32归约紧凑候选。QK复用普通池，不再有独立QK阵列。原100MHz和宿主默认没有修改。

- 同seed17，原320路较大配置581.15µs、16.79168mm²；新256紧凑配置626.78µs、13.61588mm²，面积减少18.91%，时间增加7.85%。面积边界为Attention逻辑＋整个共享池＋512KiB Attention/160KiB权重SRAM，已乘0.81一次。
- 256紧凑三seed均值626.84µs，范围626.78～626.95µs。片上活动及背景覆盖能量约364.85µJ/本次单层前缀；seed17片上平均0.582W。每次MAC/ADD和KV流量未减少，能量没有随面积同比下降。
- 4pJ/bit外存情景，合计约2.0937mJ、3.340W；外存价是敏感性假设，不是LPDDR功耗实测。另有6.6/8pJ结果。
- 若把DMA24KiB保持、向量/norm/DMA SRAM以及codec公共预留全部归属本模块，面积为17.21316mm²。这些在整机只能计一次，不与前一面积再重复相加。

详细表见[REPORT_ZH.md](REPORT_ZH.md)，配置见[PROFILE.json](PROFILE.json)，机器分项见[RESULTS.json](RESULTS.json)。11项原生LPDDR回放和12项解析初筛已完成，三seed输入SHA保留；同seed MAC/样本/唯一V、SRAM字事件及DRAM字节/地址摘要守恒，仅明确的K分组归约ADD数改变。原320/640控制时延逐值复现。

## 接入合同

1. 在宿主make_model之后、任何预取之前，调用`attention_integrated_tt250_20261107.model.install(model, PROFILE["case"])`。依赖既有compact1216宿主与冻结runtime，不能装到稠密/其他K或其他SRAM几何后仍套本次数字。
2. SRAM仍100MHz、1216KiB/304bank/16B/1RW；LPDDR5X derived8533、256credit、**24KiB返回保持**。旧交接32KiB是SRAM保留区，不是实际返回保持容量。
3. QK每组租用64路，256池同时最多4组，8组排队；PV每头2路保留所有128维FP32部分和。采样/筛选按4服务核排队，保留每组有限队列；不要仍按8核计吞吐而只付4核面积。
4. QK采用四个128B微块转置暂存/组及4×32B读FIFO/组，共5KiB寄存器；同一实际SRAM读写和bank争用已经计时。PV16KiB状态及2KiB暂存已在PV项内，不能重复计。
5. `pricing.price(result)`返回独占逻辑、672KiB归属SRAM、共享支撑、活动增量、门控背景及外存敏感性。用于整机时把本层动作和实际驻留时段交给同一价格规则，不能简单把本次平均功率乘完整token时间。

## 仍需分清的估算

PV2、微块暂存/选择器和额外根门控没有新集成RTL/PT；用PV4算术分解、真实单元计数和旧保持活动标定，并给能量敏感性。归约/输出/格式外围沿既有明确代理，不宣称全部同TT250实测。正确宽分数max/差值/量化前端预留面积/能量，额外保守延迟5.2µs尚未计入原生时延，不把旧S12轨迹冒称新算法精度。

256池理论BF16权重消费128GB/s，320池160GB/s；外存标称136.4606GB/s。192池降到96GB/s后明显拖慢。本结果支持256附近是面积折中，不能说各阶段均已跑满DRAM。完整lm_head、整机36层和新PPL由相应任务另行验收；本模块无这三项新结果。前布局时序余量很小，后布局/CTS/PHY/CDC实现另验。
