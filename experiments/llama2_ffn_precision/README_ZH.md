# FFN精度分解与低于256拍的验证

Issue [#19](https://github.com/rayggxia-workspace/pbit-llm-qwen-baselines/issues/19)，负责人@jieruiz，2026-10-18。Llama2结果与Qwen历史结果分开；本次不测试Llama1，不训练模型。

## 先说明判断

**当前固定权重、8位概率门限、精确累加的矩阵，不应继续把4096次IID采样作为硬件目标。** 对每个固定输入完整遍历0～255的门限，各用一次，256拍就能精确得到量化后的矩阵结果。因此，新随机方案首先要争取低于256拍；更严格的确定性竞争者是约8个输入位平面周期的位串行矩阵。

此前只观察IID采样的PPL收敛来选择4096拍，没有纳入完整枚举和位串行基线，是比较方法的缺项。4096保留为历史数值对照，不能据此说明它在硬件上合理。短序列能否在完整模型上保持PPL，本次实测，不用单路方差替代答案。

## 为什么256拍完整遍历精确

当前编码是幅度整数`a=round(256*abs(x)/S)`，截到0～255，概率为`a/256`，符号单独保存。注意：**这实际是8位幅度加符号，不是总共8位的signed INT8。**

每拍输出`b=(r<a)`。当r把0～255各用一次时，b恰好有a个1。固定权重矩阵的时间累加于是满足：

```
256拍的平均矩阵输出
= Σ_i [ 固定权重_i × 符号_i × 固定尺度_i × (a_i / 256) ]
= 对同一量化输入做确定性矩阵乘法
```

64个输入共用一条完整门限序列也不影响这一恒等式。当前FFN先完成x→gate/up，再完成数字SiLU(g)*u，得到固定z后重新编码，再完成down；两个线性阶段分别成立。这里的周期是每个映射矩阵tile的计算帧，不是整个FFN无视容量只花256拍。

严格前提：采样期间权重、输入和尺度固定；空间/时间加法精确；同一tile部分和恢复顺序和舍入规范一致。OR近似、累加饱和、在线非线性、旧三路AND、双边随机权重、物理p-bit连续概率，都不能直接套用这个256拍结论。双边随机的边际各遍历一次也不保证联合乘积正确。

普通8位最大长度LFSR只有255个非零状态，不能自动声称完整遍历256状态；需要补零或另设计数/排列。当前A8编码最大255/256，不表示概率1，不能悄悄改成除255。数值计数压缩不复现具体LFSR或物理器件。

## 比IID更合适的短序列

将256个门限划成T个等宽区间，每个区间随机取一个门限，T取16/32/64/128。令区间宽度w=256/T，一个输入最终事件数为：

```
C = floor(a/w) + Bernoulli((a mod w)/w)
估计概率 = C/T
```

直观上，除了包含a边界的那个区间，其他区间的0/1个数都确定了；随机性只用于最后一个舍入位。这是**随机分层/随机舍入**，无需4096次有放回反复抽取。实现共享64时，每token、每组、每区间共用一次jitter，同组所有输入查自己的边界区间；保留相关性，不能伪造为逐特征独立binomial。

硬件上可保留原比较器。例如T64，8位门限由“高6位区间计数器＋低2位随机数”拼接，每拍进入下一区间，仍向64路共享广播。无需随机洗牌或存储64个门限。实际PRNG/LFSR的相关性、种子复用及能耗仍需另测；本次PPL先使用理想均匀jitter。

| T | IID最大标准差 | 分层最大标准差 | 相对4096拍的采样帧长度 |
|---:|---:|---:|---:|
| 16 | 0.12500 | 0.031250 | 1/256 |
| 32 | 0.08839 | 0.015625 | 1/128 |
| 64 | 0.06250 | 0.007813 | 1/64 |
| 128 | 0.04419 | 0.003906 | 1/32 |
| 256 | 0.03125 | **0** | 1/16 |
| 4096 IID | 0.007813 | 不需要增加到此长度 | 1 |

公式：IID方差=p(1-p)/T；分层方差≤1/(4T²)。这些是**单路概率估计的最坏上界**。64拍分层的最坏标准差上界等于4096拍IID的最坏上界，不意味着两个网络的PPL必然相同。稀小概率、带符号权重、组内协方差及非线性会影响实际误差。

固定每区间中点则不需要随机数，也要作为对照。它接近较低位激活量化，但严格比较器的中点tie规则与普通RNE不同，且事件数允许0～T、含端点1，例如T16有17个输出等级；因此本次称“midpoint T16”，不将其冒称为完全相同的常规4bit INT量化。

同样的AND小单元还可接确定性输入位平面：a的8个二进制位逐拍输入，按1、2、4…128移位恢复。**在权重位平面并行、归约带宽充足的前提下，主体约8拍加读写/流水开销**；若权重也串行或tile复用，周期相应增加。因此T<256只是第一道门槛，不能证明优于低位MAC或8拍位串行；需同工艺、同容量、同精度的PPA与系统调度比较。

低差异和确定性位流缩短SC序列已有研究，本分析不是新发明。参考Najafi、Lilja、Riedel，ICCAD2018，[Deterministic Methods for Stochastic Computing using Low-Discrepancy Sequences](https://mriedel.ece.umn.edu/wiki/images/1/1f/Najafi_Lilja_Riedel_Deterministic_Methods_for_Stochastic_Computing_using_Low-Discrepancy_Sequences.pdf)，DOI10.1145/3240765.3240797。该文一般双流乘法与这里固定权重单边线性恒等式的适用条件不同。

## 什么结果才说明值得继续

1. 先看W8/A8无采样相对BF16的损失，再看Q10增量；若基础数制已经不合格，增加采样不能修复确定性损失。
2. 分层低T必须接近相同数制、相同后处理的确定性基线，比较三种子，而不是只与BF16或旧Qwen横向比较。
3. 分层需与相同T的midpoint及合理低位MAC/位串行硬件比较。若只是低位量化就已够好，随机性没有额外收益，应采用更简单实现。
4. 即便T4096→T64帧长减少64倍，也只直接影响采样动态动作；权重装载、SRAM保持、数字SiLU、残差、Attention、DRAM背景等不会全部同比减少。TLM须重排时序再算总能耗，不能宣称整机64倍。

权衡允许结论是“这个固定线性矩阵采用确定性位流更合适”，p-bit仍可用于Ising更新或原生概率非线性。不能为了维持随机计算叙事，跳过更强的确定性对照。
