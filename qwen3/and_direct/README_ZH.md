# 八位三流AND直接驱动Wd（Issue173）

目标：量化后的g、sigmoid(g)、u三条独立0/1流经AND后，直接选择Wd权重贡献；只在Wd各输出端累加。不先统计z，不对z重新缩放或生成第二条随机流。本次是推理模拟，无训练、RTL或PPA结论。

## 数值与时序契约

- Qwen/Qwen3-4B后训练版，36层全部替换FFN，Attention保持准确SDPA。
- x到gate/up延用固定四档、A8/W8、共享64路、分层T=K=64。该段恢复仍为FP32参考，不宣称整个FFN已经bit-true。
- g/u幅度8位另带符号，TRAIN校准冻结的每64通道二次幂尺度；幅度码0..255，概率q/256。sigmoid输入signed8、步长1/8、范围[-16,15.875]；LUT输出概率8位另true-one。
- 每拍三条流门限相互独立，在通道及时间上也独立。同一AND事件广播给所有Wd输出，因此保持跨输出相关性。g/u在整个采样块中保持不变。
- z符号是sign(g)sign(u)；幅度尺度是SgSu。符号与尺度不能因只传一位幅度而省略。
- 固定Wd为INT8[-127,127]。每输出64通道tile，预先把各输入组的weight_lsb*Sg*Su编码为16位非负系数和一个共同二次幂指数。系数乘法在局部Wd输出归约后执行，不能当免费操作。
- 按最坏上界N*T*127*65535，采用signed52输出累加器；支持本模型N=9728及T<=16384。这是保守功能格式，不是最优面积结论；中间矩阵结果并不只有8位。
- 末端按整数商/余数执行round-to-nearest-even，再以二次幂恢复为BF16进入残差；非零subnormal和overflow显式拒绝。

## 加速模拟为何等价

给定g/u，每个通道AND事件概率严格为gc*hc*uc/256^3。用Binomial(T,p)产生事件总数，保留相同通道事件驱动所有输出的关系。整数加法可交换，所以它与逐拍加带符号权重具有相同输出分布；这不是平均值替代，也不是要求硬件存一份z计数。真实逐拍比较和输出累加由test_core独立核验。

Wd软件加速只允许局部整数点积绝对上界小于2^24，禁止TF32，使FP32容器中的点积严格精确；随后转int64做定点系数乘法和输出累加。按T自动切分局部点积，CUDA与CPU整数参考需逐位相同。

## 扫描与验收

Slurm五个分片：控制组含BF16、W8、旧z重编码、直连条件均值原尺度、直连条件均值有限系数；另四个分片扫描T=64/256/1024/4096，各三个seed。每片先重跑同轮BF16。8段上下文2048、每段128目标，总1024目标；是后缀PPL初筛，不是完整WT2。所有前缀同样替换FFN。

运行前验证源码、模型、语料与两份校准SHA；结果必须status=completed、documents SHA及36层覆盖完整。三个种子完整后才报告均值。模拟时间不是芯片延迟。三流独立随机源成本、16位尺度系数运算、52位归约和输出转换尚无本任务PPA，不以本次PPL声称节能。
