# 编码/恢复维护规则

- 计数总线的维度不证明语义兼容。接合前明确 rail 的符号对象、W8表示与 bit7 权重，并保留 −128 反号反例。
- 除T、FP32转换、scale乘法和档间/跨k求和的顺序是接口的一部分。改动时保留次正规数反例，不把整数等价直接扩展成浮点或PPL等价。
- 周期报告分开 post-edge 可见、pre-edge 握手、II、实例数和有限槽。不能用默认 latency 代替 STA，或把完整tile当一次标量恢复。
- Buffer数量不携带payload身份；有限信用和数据ID必须保持同一顺序。后端模块缓存必须绑定所有被载入依赖的hash。
- ready/valid测试驱动在阻塞后必须保持valid与payload直到握手或reset，并分别检查队列中结果和核内在途结果的reset清空。
