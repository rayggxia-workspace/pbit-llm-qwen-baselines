# Qwen双随机FFN：截断与固定二次幂范围

Issue39；base c1555ae6594c863011a70845d88c950a68de732b。只修改24个FFN的算术，Attention保持原BF16 SDPA，无训练。

用户要求牺牲少数大幅度值，减少多数小幅度值的采样误差。新编码上限S表示真实幅度：超出S的值截到S并输出恒1；正常概率为q/256，q是8位，符号独立。严格保留255/256与1两个端点需要额外饱和状态，不能把普通R8比较器称为自动支持p=1。

流程保持：x编码→Wg/Wu双随机精确计数→恢复FP32 g/u→准确SiLU(g)×u→z重新编码→Wd双随机精确计数→BF16残差接口。并非全比特流非线性。

实验预注册：

|策略|输入x/z范围|权重范围|
|---|---|---|
|control|与Issue32动态64路absmax完全相同，最高255/256|原row64|
|dynamic075|每token每64路最大幅度×0.75，超限恒1|原row64|
|dynamic050|同上×0.5|原row64|
|dynamic_z050|x最大幅度、z最大幅度×0.5|原row64|
|fixed999|train前8192token、每组绝对值99.9分位，离线固定|原row64|
|fixed9999|同上99.99分位|原row64|
|fixed9999_potA|99.99分位上取整为2的幂|原row64|
|fixed9999_potAW|同上；W行×64最大幅度上取整为2的幂|二次幂；真实p1端点|

每组固定尺度只用train校准，不用test调阈值；W从相同历史INT8解码值重新编码，不换基础权重。自然IID，输入组内共享随机字，权重流逐连接独立，用准确条件二项分布避免展开时间；无OR/高斯近似/优化序列。

全8策略先在512token前缀、T256、seed0/1/2加无采样期望对照。control、dynamic075、fixed9999_potAW事先指定再测T128及2048token/T256，避免按测试分数挑选确认策略。所有替换分数仍是前缀诊断，不能称完整WT2。每次先重跑未改BF16完整WT2参考并核验模型/语料/源代码hash。完整滑窗采样评估需另据预算决定，本轮不隐含已完成。

固定二次幂范围可去掉在线组最大值归约、任意比例除法，但BF16转幅度码仍需指数对齐、舍入和饱和。不同组计数必须按其尺度恢复后才能跨组相加。没有新RTL/PT或能耗改善实测。

执行：先以run_clipping.py prepare核实环境和生成train校准，再通过run.sbatch的Slurm数组逐项worker；submitted源快照不可改，输出在个人项目outputs/<精确提交>/。原始校准及长结果只留授权服务器，Git发布代码/汇总/校验索引。
