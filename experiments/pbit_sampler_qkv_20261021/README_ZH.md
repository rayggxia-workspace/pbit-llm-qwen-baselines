# 真实QK/V上的p-bit采样器选型

Issue78，jieruiz，2026-10-21。独立分支`task/78-sampler-qkv-benchmark`，base `5b26c80c28ab22383f12ab31046dd723ca985abb`。用户授权比较最新采样方案，特别是不同真实QKV下的采样更新预算；不是新的模型PPL或PPA评测。

## 方案与比较口径

1. 准确Softmax IID参考、原校正空参考拒绝采样。
2. 全候选并行赢家保持，共同c=max(z)+0/2/4；每轮独立重采所有候选，活跃地址均匀仲裁，保持也计样本。
3. 两比特+全局均匀挑战者；Barker单p-bit+全局均匀挑战者；Barker+固定XOR逐位提议。
4. 旧CTMC仅作质量参考：burn16、spacing4，S128/512。它的无量纲过程时间及软件事件压缩不换算成数字更新周期。
5. 补充赢家max0和Barker的8位驱动对照。这里量化的是sigmoid输入，步长1/8、负幅度范围[-31.875,0]；Barker正差可用`1-sigmoid(-abs(delta))`。不是8位概率门限或Q/K INT8，不预设量化后仍严格等价原Softmax。

采样器使用理想独立Bernoulli响应，未包含物理失配/时间相关。每行3seed×8重复，链从argmax地址初始化，burn0/32/128；相同轨迹前缀给出采样预算曲线。并行保留预算上限4096，串行32768；超过网格仍不达标就标记未达标，不补IID或只挑成功轨迹。

主指标为真实64维Attention输出的均方误差。用解析IID单样本方差归一化后，独立S次采样的期望MSE恰为1/S。对照IID128和IID512目标，不用有限地址直方图TV当主要选型指标。逐seed/重复误差保留，汇总给出不确定性；扫描网格上的首次达标是探索性观察，不是精确最小轮数。第二文本窗口可用于检查第一窗口选参的迁移性，不能把每行选最优偏置当免费控制器。

## 轮数、随机服务与时钟

- 并行方案每完成一轮产生一个链输出，所需p-bit服务数=N×更新数；另记均匀仲裁调用和有界整数的理论平均公平随机位数。
- 单p-bit/两比特每轮分别1/2次Bernoulli服务；全局挑战者还需要索引随机数、分数读取，Barker还需差分/驱动装载和状态反馈。
- 校正拒绝法按真实提议次数计费，另计全零校正公平位。不能把接受样本数当提议周期数。
- 旧CTMC的时间单位独立列示，拒绝帧、Markov更新、输出地址数三者不混称。
- 本实验不测芯片周期。理想1更新/拍只可作为显式下限；实际需器件等待、流水启动/间隔、反馈延迟、物理p-bit并行数及bank波次数。并行固定c可提前流水候选，Barker单链受赢家/分数反馈依赖限制，不能无条件按同一II计时。
- 新query改变目标，不能假定旧赢家已经平稳。原始V重复地址可按计数复用，但分母仍是总观测数。
