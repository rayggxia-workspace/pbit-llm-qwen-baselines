# 分层采样：实际精度、功率与能量、文献定位

## 一眼能看到的结论

| 问题 | 目前结论 |
|---|---|
| 64拍分层能否保持当前FFN精度？ | 首批完整PPL约6.76，相同W8/A8无采样基线5.038；还没有达到同精度。不能据“最坏方差界”宣称替代4096 IID。 |
| 分层在相同拍数下是否有价值？ | 理想独立分层偏移、固定输入线性矩阵下，估计无偏，输出方差不高于同拍数IID；完整LLM PPL还要实测。当前没有IID64完整PPL，不能给同T的PPL收益数字。 |
| 电路平均功率是否变化不大？ | 主体面积和时钟负载可能接近，但有序门限显著改变组合翻转，不能预设功率一定变化很小。尚无分层波形PT数据。 |

比较分层与IID时都采用准确SiLU；不能将它们与另改后处理的Q10行当作严格单变量对照。256枚举+Q10与确定性Q10的完整PPL和NLL完全一致，已验证“完整遍历精确”；准确SiLU下应参照a8_exact。

同流长确定性中点也已完成：64拍为5.995513，比随机分层64的6.758371更好；128拍为5.412020，比随机分层128的5.308904稍差。**随机性并非普遍有利**：64拍更像是噪声过大，128拍的无偏舍入有一定数值收益，但还没有证明硬件上优于更好的确定性编码。

需要特别说明中点对照的规则：严格比较器下，T128中点恰好等于C=floor(q/2)，是向零截去一个幅度低位；分层128则是floor(q/2)+Bernoulli((q mod2)/2)。因此本对照不是最优RNE或重新校准的常规7位量化，不能以约0.103 PPL优势宣称随机方案已优于全部确定性方案。

此前给出的“64分层的最坏标准差界等于4096 IID的最坏界”数学上成立，但不是模型精度预测。IID的最大方差出现在p=0.5，而本模型SwiGLU输出的平均编码概率只有约0.0063。工程上应看实际概率分布、尺度、带符号权重及共享相关性，不能只比较两个不同位置的最大值。

以最小非零码q=1、p=1/256为例，概率误差换成A8的1/256步进单位：

| 估计方式 | 恢复的幅度码 | 标准差，A8 LSB |
|---|---|---:|
| IID64 | 4×Binomial(64,1/256) | 约1.996 |
| 分层64 | 0或4，概率分别3/4、1/4 | 1.732 |
| IID256 | Binomial(256,1/256) | 约0.998 |
| 分层128 | 0或2，各1/2 | 1.000 |
| IID4096 | Binomial(4096,1/256)/16 | 约0.250 |
| 完整256遍历 | 恒为1 | 0 |

所以分层64比同T的IID64减少了方差，但对于这种小概率，其噪声仍可能高于IID256，更远高于IID4096。T64的有效幅度步进是S/64：偶发事件幅度为S/256的4倍。它保持均值，并不保证有限帧内的重构误差小。

128拍时，偶数A8码可以精确恢复，奇数码只在q−1与q+1之间随机；64拍则只有4的倍数精确，其余残数的误差更大。因此，128相比64的效果不能只按拍数线性外推。

128拍已有3个完整种子，当前PPL约5.3089，比无采样量化基线高约5.37%；比已有IID256约6.253更好且采样减半。种子是否齐全以上表为准，不能直接承诺所有任务质量已满足。

| z平均编码概率 | 0.006311 | 0.006302 | 0.006188 | 0.006291 |
| z编码本身为0的比例 | 37.744% | 37.709% | 38.043% | 37.776% |

分层64中z每帧平均约0.396个事件，很多非零编码也变成零事件；未来层还要承受这些扰动。上述统计支持“小概率与粗脉冲是重要限制”，但不同随机模型的隐藏状态也会变化，尚未做只随机gate/up或只随机down的消融，不能据此断言PPL全部由down导致。

特别是分层128的z零事件比例仍略高于IID256，但PPL反而明显更好，说明零事件比例本身不是充分的精度指标。还要看其他幅度码的误差、矩阵加权方向、共享相关性以及非线性传播。

一般公式更有用。令w=256/T、u=(q mod w)/w，则

```
C = floor(q/w) + Bernoulli(u)
Var(C/T) = u(1-u)/T²
IID方差 = p(1-p)/T
```

同T时，对整个共享64组也能说明方差改善：把某个固定输出的每拍值记为f(r)，分层各区间独立取一点，其平均值方差等于“区间内方差项”；IID还多了“区间均值之间的方差项”。这一结论允许固定带符号权重，不依赖逐输入独立。但理想分层偏移的独立性需要实际PRNG验证，完整网络的非线性损失也不由矩阵方差单独决定。

## 每拍功率与每次计算能量

**减少周期主要改变时间和能量，不自动使电路的瓦数按同倍下降。** 同频、同阵列下，可写成：

```
一次矩阵能量
= 权重/输入装载与编码能量
+ 采样窗口内的逻辑、寄存器、时钟及保持能量
+ 结果恢复与写回能量
```

例如假设采样窗口功率一直是1mW、频率100MHz，不含启动或搬运：4096拍=40.96µs=40.96nJ，256拍=2.56µs=2.56nJ，64拍=0.64µs=0.64nJ。**这是单位说明，不是我们的新PT实测。** 若1拍启动固定存在，窗口应为4097、257、65拍。

还必须使用公平基线：64拍比4096 IID少64倍采样周期，比精确256遍历只少4倍；合理的8位输入位串行在权重位平面并行、归约带宽足够时约8个主体周期，64拍反而更多。不能跳过这些对照，也不能用PPL6.76的能耗搭配PPL5.04的精度作同精度宣称。

目前更有希望的128拍，分别比4096 IID和256精确遍历少32倍和2倍采样周期；相对约8拍位串行仍更长。最终应比较满足同一精度要求的完整实现，而不是选最差的旧IID作为唯一能效分母。

假设活动功率不变、时序无其他瓶颈，若原能量中完全不受采样缩短影响的比例是f，归一化能量为f+(1-f)×Tnew/Told：

| 不受影响的原能量比例f | 4096→64的有条件能效改善 | 256→64的有条件能效改善 |
|---:|---:|---:|
| 0% | 64倍 | 4倍 |
| 50% | 约1.97倍 | 1.60倍 |
| 80% | 约1.25倍 | 约1.18倍 |

这些是假设情景，不是同精度测量或当前整机预测。采样变短后，权重带宽、数字SiLU/Q10和写回可能成为瓶颈；SRAM/DRAM背景能量需随新的调度和低功耗状态重算。当前TLM仍有按(T+1)×period乘旧活动功率的近似，没有分层波形标定，不能用它证明额外低翻转收益。

## 电路中不仅是随机源发生变化

T64的门限为r_t=4t+U_t，U_t为均匀0～3。每个r_t都大于前一个，因此固定阈值的稳态输出必是`111…000`，有效采样序列内至多翻转一次，另计帧边界、配置和复位。实际控制器须按有效采样推进区间计数器；若停顿时PRNG仍自由变化，边界区间的比较器还可能翻转。该界不涵盖物理毛刺或空闲活动。

PPL程序压缩的是联合事件计数，不记录帧内排序。这里讨论的低翻转收益对应具体选择的“升序区间计数器”硬件实现；将同一组门限换一个顺序，精确线性结果可不变，但物理活动和功率会改变。不能从PPL日志直接提取这个功率收益。

| 部分 | 同64拍，IID改为有序分层 | 4096改为64拍 |
|---|---|---|
| 门限生成 | 可复用6位帧计数器、拼接2位随机偏移；比较器不改 | 有效时钟减少 |
| 32位PRNG | 只取低2位并不会自动减少32位内部翻转 | 更新次数可减少 |
| 比较器输出、固定W的AND | 稳态输出翻转通常显著减少 | 服务周期减少 |
| 空间精确popcount | 纯组合树的输入活动减少可能有利；内部进位和毛刺仍需测量 | 树面积基本相同 |
| 时间/缓存累加器 | 连续相同的非零部分和仍需累加，寄存器仍会翻转 | 更新次数减少，专门综合可缩窄部分计数位宽 |
| 时钟、概率/控制寄存器 | 未门控部分不会随数据翻转减少而自动消失 | 活跃窗口缩短 |
| 权重SRAM | 容量和每tile首次装载字节数不变 | 保持时间可能缩短；读次数依赖实际接口 |
| 数制转换、后处理、写回 | 基本不变 | 固定开销不按采样倍数下降 |

例如p=0.5、64拍，IID比较器输出的帧内期望翻转数为63×2×0.5×0.5=31.5；有序分层为1。但不能把31.5倍套到整核功率：累加器、时钟、PRNG及二进制归约内部节点都不受这个单路界限约束。多输入集中在同一拍变化还可能形成峰值和毛刺，带时延门级活动更有说服力。

“只需2位随机偏移”也不等于换成2位最大长度LFSR：后者只有3个非零状态，不能自然均匀给出0～3。可以先保留32位PRNG并取2个输出位，待实际序列/PPL核验后再单独优化源的功耗。

旧任务38015538可作为“固定开销确实存在”的证据：G1/B1/case3在100MHz、SS、N64/W8、12位独立随机字、4096拍下为1.283732mW，窗口40.97µs，含概率/符号/权重寄存器和计算树，但不含RNG/SRAM/CTS/真实互连。该旧核心概率、权重和输入符号寄存器约占66.8%的功率，且数据不变时仍有时钟功耗。**这些比例不能迁移为当前A8共享64＋SRAM体系的分层功率数据。** 源索引见文末本地证据。

## 为什么论文里看起来较少

相关研究并不少，名称和目标往往不同。以下是核实过的原始论文，不据有限检索判断整个领域的流行程度：

| 原始研究 | 与当前问题直接相关的内容 |
|---|---|
| Liu、Han，DATE2017，[Energy Efficient Stochastic Computing with Sobol Sequences](https://past.date-conference.com/proceedings-archive/2017/html/0464.html) | 用低差异Sobol序列缩短达到目标精度的流长，并考虑生成器成本；不能迁移其具体能效倍率到我们的LLM。 |
| Najafi、Lilja、Riedel，ICCAD2018，[Deterministic Methods for Stochastic Computing using Low-Discrepancy Sequences](https://mriedel.ece.umn.edu/wiki/images/1/1f/Najafi_Lilja_Riedel_Deterministic_Methods_for_Stochastic_Computing_using_Low-Discrepancy_Sequences.pdf) | 讨论unary流、配对/旋转和提前截断精度。论文的通用双流乘法约束比当前单边固定W更强。 |
| Wu，ARITH2021，[Dither computing: a hybrid deterministic-stochastic computing framework](https://arxiv.org/html/2102.10732v2) | 混合确定/随机编码降低误差；§VI说明不同操作数的格式和多级运算的重编码成本，§VII联系随机舍入。与我们的思想相近，不是同一算法。 |
| Moghadam等，ASP-DAC2024，[P2LSG: Powers-of-2 Low-Discrepancy Sequence Generator for Stochastic Computing](https://arxiv.org/html/2309.05235v2) | §II-A直接介绍等分区间、每区间取随机点的Latin Hypercube；§III/Table I测试它与Sobol等。它研究双流AND的联合分布，不能把其误差表当本模型PPL。 |

下面是结合论文与我们架构的分析，区别于论文直接结论：

1. **我们只需一维积分，通用SC往往需要联合乘积。** 两个p=0.5的同向`111…000`流做AND，输出仍约0.5，目标乘积却是0.25。两个8位概率的乘积还可能是1/65536，256拍的单一0/1输出流不能精确表示所有乘积；而当前W是多位固定系数、读出是加权多位计数，不是双流乘法。
2. **有序分层不适合任意提前停止。** 在256门限升序遍历中，p=0.5的前64拍全为1，提前停并除64会得到1。当前应预先选T，再遍历其完整T个区间；Sobol/bit-reversal等排序更关注不同长度前缀的均匀性。
3. **我们采用帧末数字非线性，流序不被下游直接使用。** 通用多级SC、MUX、非线性或反馈电路需要更复杂的相关性和时序控制；为此文献常研究多维低差异序列、旋转和格式转换。
4. **它本质接近低位随机舍入。** T64的事件数C=floor(q/4)+Bernoulli((q mod4)/4)，只有最后一个舍入位随机。若普通低位MAC或位串行已经更省，没必要坚持64拍流的形态。必须保留midpoint和合理确定性硬件对照。
5. **不能全局替换Ising随机源。** FFN帧内q固定；Ising/Gibbs的输入概率随状态改变，需要正确的单次条件更新。分层门限每拍只在小区间均匀，会改变这种转移律。它适合作为FFN本地门限调度器，不应直接替换所有模块的均匀随机数。

OR需按具体共享关系分析：不能把精确线性证明直接迁移到任意OR归约。若OR各路原本就在同一share64组、共用同一个r，则IID基线的OR期望已是max概率，分层积分同一r未必新增均值偏差；跨组、独立流或其他重新配对则另当别论。因此不能将旧G4功耗与本次G1精确PPL拼成同一个结果。

## 下一步应验证什么

- 完成128拍三种子与midpoint对照，再决定可接受的流长。64拍尚未保持基线精度，不能先按64拍宣称同精度能效。
- 若低T仍差，优先考虑train校准的Sx/Sz、分组粒度或只在部分投影使用短流；必须另跑确定性量化与逐投影消融，不能根据零事件比例就断言因果。
- 最小PT矩阵：同A8、同share64、同固定W和G1精确树，比较IID64、分层64、midpoint64、enum256、IID4096。先固定相同累加器位宽和32位PRNG隔离序列影响，再单独综合短流缩位版本。
- 用同一批真实x/z/权重tile，记录种子和SHA；报告动态功率、时钟/寄存器功率、泄漏、采样帧能量、完整frame能量和时序。RNG单列或纳入，不能省略。旧零延迟活动结论需与带时延毛刺分析区分。
- 重排TLM后再算整机：权重/激活搬运、数字后处理、SRAM保持和DRAM状态都要计入；GPU本次评测耗时不能代替ASIC时钟周期。
