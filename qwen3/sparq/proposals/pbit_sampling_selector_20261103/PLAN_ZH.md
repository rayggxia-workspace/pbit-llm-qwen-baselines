# SparQ粗筛选的p-bit采样替换方案与验证计划

日期：2026-11-03，北京时间。负责人：amlink1219。关联任务：[Issue234](https://github.com/rayggxia-workspace/pbit-llm-qwen-baselines/issues/234)。

本文是待实施的设计与实验安排。本次没有启动模型推理、训练、RTL、EDA或服务器任务，没有新增PPL、功耗、面积或延迟结果。

## 1. 本轮优先方向

**先尝试沿用后级的赢家保持（WH）Ising采样机制，在SparQ粗QK之后直接采样生成256个候选上下文。保留数字粗QK，暂不引入独立的小网络。**

推荐先后顺序：

1. 固定粗分布，赢家保持有放回采样，经过地址去重得到候选集合；这是首个实现。
2. 如果重复采样成本太高，再研究屏蔽已选地址、调整粗阶段温度等适配。
3. 采样直方图再Top-k作为诊断或备选；粗QK随机计算、低位量化等列为后续方向。
4. 独立p-bit门和小神经网络本轮不实现、不训练；全局k-hot Ising也不作为首轮。

首轮固定原Qwen3-4B权重，先验证推理可行性。本文不改动已有“11组概率Attention训练＋2组数字控制”的矩阵；通过本方案的筛选器之后，才讨论是否需要增加适应训练。

## 2. 当前SparQ与拟替换位置

模型参考为后训练版`Qwen/Qwen3-4B`，revision：`1cfa9a7208912126459214e8b04321603b3df60c`，不是Base。每KV组由4个Q头共享K/V。

当前新计划：`r=32`、`K_total=256`、`recent=32`；最近32个位置包含在256候选内。

```text
当前SparQ：
Q选32维 → 扫描全部历史K的这32维 → 各Q头粗Softmax
       → 四头概率合并 → Top-k＋最近窗口 → 256候选
       → 候选完整QK → 后级Softmax/Ising与V累加

本轮主线：
Q选32维 → 同样的数字粗QK → 各Q头赢家保持采样
       → 混合地址流＋去重＋最近窗口 → 256候选
       → 候选完整QK → 原后级Softmax/Ising与V累加
```

本轮尝试去掉显式粗概率向量计算和Top-k候选选择；**仍需读取全部历史K的32个维度，并计算粗QK**。它是采样选集的新算法，不是原Top-k的等价实现。

现有粗分数记为`z[h,i]`，已经包含SparQ的按头温度缩放。原组分数可写为：

```text
p[h,i] = Softmax_i(z[h,:])
u[i]   = (p[0,i] + p[1,i] + p[2,i] + p[3,i]) / 4
```

原SparQ按`u`排序选候选。除以4不影响排序，却便于将`u`解释为概率分布。

单头Softmax不改变排序，但四头分别归一化后求和，通常不能用`sum_h z[h,i]`替代；后者另列近似变体。项目代码明确区分`probability_sum`和`raw_score_sum`。[来源1、2]

## 3. 固定术语与候选契约

| 符号 | 含义 | 计量范围 |
|---|---|---|
| `N` | 当前有效、因果可见的历史位置数 | 每KV组；主测约2048 |
| `K_c` | 传给后级的不同候选数 | 目标`min(256,N)` |
| `R` | 强制保留的最近有效位置集合 | 最多32个 |
| `K_free` | 还需采出的非近期唯一候选数 | `K_c - len(R)`，2K时为224 |
| `M_c` | 粗阶段实际观察到的地址数 | **每KV组四头合计**，包括保持、重复和近期命中 |
| `M_cap` | 一次粗筛允许的最大地址观察数 | 不含预热；超限明确报告 |
| `B_c / gap_c` | 粗阶段预热更新数／观察间更新数 | 与后级单独配置 |
| `S_v` | 后级V采样数 | 每Q头；例如128 |

**`K_c=256`、`M_c=256`、`S_v=256`是三件不同的事。**

粗候选必须去重。不能将重复地址填成多个候选槽位交给后级：这会让该位置获得额外的重复权重。后级V采样本身仍允许重复，重复次数应正常参与V累加。

短上下文`N<=256`直接把所有有效位置作为候选，不必做粗筛；后级仍执行其规定的采样。因果和padding mask贯穿全部步骤，不能选未来或无效位置。

## 4. 首选方案A：固定粗分布的赢家保持采样＋去重

### 4.1 如何沿用现有赢家保持

保留数字选维度、粗QK及原SparQ温度。每个Q头分别维护阈值与赢家状态，不先显式计算Softmax。

粗阶段将`z[h,:]`接入现有有限位前端：

```text
FP32粗分数 → signed12/F4 → 各头有效最大值/扩位求差
          → U8负驱动幅度 → 冻结P8 sigmoid LUT
          → 候选独立R8比较 → 赢家保持与均匀仲裁
```

有意复用数制和控制机制，但粗分数的范围、P8零阈值及有限混合必须重新验证，不能继承后级精确QK分数上的检查结果。各头初始化为该头实际argmax。首个工作点采用`B_c=32、gap_c=1`，这是起点，不是已证明足够的预热与去相关设置。

一次WH更新严格沿用现合同：当前赢家自己的提议为1时保持；全零时保持；否则从活跃位置均匀选新赢家。不能改成取第一个活跃位置，也不能仅在赢家切换时记录输出。[来源3]

理想连续sigmoid下，每头的稳态可对应其Softmax。实际P8下，每头平衡分布是：

```text
b[h,i]  = LUT[h,i] / 256
w[h,i]  = b[h,i] / (1 - b[h,i])
pi[h,i] = w[h,i] / sum_j w[h,j]
```

因此实际采样首先近似的是`mean_h pi[h,i]`，不等于保证精确采到`u[i]`；有限预热和相关性还会增加差异。这里只是数学诊断，部署不需要通过上述除法显式重建概率。

### 4.2 四个Q头怎样共同生成一个候选集

首版采用“独立均匀选一个头，再推进该头链、读取地址”的调度：

1. 四条链分别预热`B_c`次。
2. 每次用独立无偏选择得到`h∈{0,1,2,3}`。
3. 仅将选中头的链更新`gap_c`次，保留其赢家地址。
4. 将地址送到同一个KV组的候选去重器。

若四条链处于理想稳态，观察地址的边缘分布是四头分布的等权混合。实际有限轨迹的差异如实测量。按固定轮转或每头固定配额采样也是可研究的调度，但其有限集合规律不同，应另外命名，不能混称同一实现。

四条链可以时间复用一套物理阵列，但要保存各自状态，并计入阈值装载、上下文切换与回压。四套并行则应计入四份资源，不能同时采用串行面积与并行时延。

### 4.3 去重、补满与停止规则

```text
C = 最近的 min(32,N) 个有效位置
若 N<=256：返回全部有效位置，粗筛不运行
为四个头配置阈值、argmax状态，并分别预热

M_c = 0
while len(C) < 256 and M_c < M_cap:
    h = 独立均匀选择一个Q头
    推进 WH[h] 共 gap_c 次
    i = WH[h] 的赢家地址
    M_c += 1
    if i 不在 C:
        C 加入 i

若 len(C)==256：成功，传递唯一候选
否则：记录未补满、实际候选和全部已消耗活动，标记 cap_failure
```

保持、重复以及近期命中不会增加候选数，但都消耗时间、随机数和`M_c`。仅记录切换事件会删去驻留时间，改变链的目标分布。

第一轮行级预算建议`M_cap=256/512/1024/2048`，不直接展开成四档完整模型评测。先根据覆盖、补满率和实际观察数选少数工作点。

严格固定256候选的正式比较中，超限是失败：不偷偷复制地址、准确Top-k补齐、丢弃该query或改成准确Attention。若希望研究不足256时直接使用实际集合，可另定义“可变候选≤256”变体，重新统计质量和成本，不能混入固定256主表。整模型运行遇到主线失败时保存现场并受控退出，不继续产出缺行的“完整PPL”。

### 4.4 先检查P8是否有足够支持

统计四头P8正概率位置并集，在去掉近期集合后是否至少有224个位置。若不足224，增加采样预算也无法补满；应在配置完成后尽早报告，而非浪费到cap。

支持数足够仍不保证有限时间能补满：概率可能极度集中，或者WH保持时间较长。诊断应记录：

- 非近期可达支持数、P8归零质量、四头覆盖差异。
- `M_c`均值/P50/P95/P99、补满率、重复率、近期命中率。
- 保持/切换、滞后相关、覆盖曲线；如报告ESS，说明估计对象和方法。

理想IID参考可计算：`E[唯一非近期数]=sum_{i不在R}(1-(1-u[i])^M)`。它只用于诊断，不能当作WH相关轨迹的补满保证。

## 5. 第一批适配：降低重复、改善覆盖

### B1. 只调整粗阶段温度

如果A在少数高概率位置反复停留，先试粗分数变平，例如将各头相对分数乘`gamma=1/2`，与原`gamma=1`比较。后级完整QK和V采样温度保持原设置。

它有可能降低重复、扩大P8非零支持，但会改变候选分布，不是无损变换。应在TRAIN/VAL上冻结工作点，明确整数舍入、位宽和饱和规则，不在WT2 test挑温度，不默认为已验收的P8电路。

### B2. 屏蔽已选地址的采样适配

每加入一个候选，就禁止已选和近期位置继续提议，意图逐步产生无放回集合。这值得研究，但**不是A的免费加速**。

设剩余集合为`U`。原混合分布条件化到`U`时，正确的头选择权重应为：

```text
r[h]     = sum_{i in U} p[h,i]
P(head=h | U) = r[h] / sum_g r[g]
P(i | head=h,U) = p[h,i] / r[h]
```

对于固定P8阈值的条件化，上式应将理想`p[h,i]`替换为该头原P8平衡分布`pi[h,i]`。某头剩余正支持为零时必须显式处理；若改为仅在有支持的头之间选取，应另行命名和匹配数字参考，不能静默换头或继续输出被屏蔽的赢家。

屏蔽后仍均匀选头、各头在剩余位置重新归一化，一般得到另一种分布。它可以作为“各头均衡覆盖”的新筛选器，可能有价值，但必须用相同规则的数字对照和PPL验证。

P8实现还要分开两种：

| 变体 | 做法 | 代价与风险 |
|---|---|---|
| B2-fixed | 冻结原P8阈值，只屏蔽已选位置 | 原零阈值不会自动打开；剩余支持不足时仍失败；头权重问题仍在 |
| B2-rebase | 对剩余集合重求参考最大值、重配P8阈值 | 可打开尾部，但改变量化目标，增加max、重配置和链重新建立成本 |

不能让被屏蔽的赢家继续输出。必须明确各受影响链如何重新初始化、是否追加预热、原阈值是否保留；不能假设mask后立刻进入新的稳态。

B2初版可以明确选择“均匀头＋剩余集合”的均衡覆盖语义，不为追求原混合分布的精确条件化重新引入整套粗Softmax。数字参考也应按这一语义实现。先做小状态oracle和真实行诊断，再考虑全模型。

### B3. 少量均匀探索

可另试：以小概率`epsilon`从有效非近期位置均匀抽地址，其余使用A的WH。这是明确的混合采样器，可访问原P8零阈值位置；有限cap仍可能失败。

它需要随机地址、有效性检查与去重，成本不得省略。`epsilon`只在TRAIN/VAL选择。默认不使用隐式概率下限，也不将这一混合方案称为原WH分布。

本轮只在A暴露具体问题后依次追加B1/B2/B3，不做温度×屏蔽×探索的全排列。

## 6. 其他替换方案与优先级

| 方案 | 替换内容 | 是否需训练 | 本轮定位 |
|---|---|---|---|
| A：WH地址采样＋去重 | 粗Softmax/GQA概率显式合并/Top-k | 首轮不训练 | **第一优先** |
| B：温度、mask、均匀探索适配 | 缓解A重复与补满问题 | 可先校准，不训LLM | 问题驱动追加 |
| C：采样直方图再Top-k | 用各头WH地址频率估计粗混合概率，仍排序 | 不训练 | 诊断或保守备选 |
| D：粗QK低位量化或随机计算 | 全历史32维点积 | 初测可不训；之后可能需适应 | 第二阶段；需数字INT8/更低位对照 |
| E：单链max/mean/logit-sum聚合 | 用便宜聚合分数驱动一条链 | 初测不一定需要 | 改变GQA语义，低优先 |
| F：固定K的k-hot Ising | 用基数约束直接采256位选择mask | 先验不要求训练 | 计数、耦合和混合风险较大，暂缓 |
| G：独立p-bit门／小网络 | 逐位置或逐块直接输出选／不选 | 小网需要训练 | **按用户要求本轮不尝试** |

C中，直方图还要计数、清零和Top-k，不能宣称同时去掉排序。总观察数少于224时，非近期非零计数最多只有观察数个；不能将零计数位置任意补齐后称为已经采到224个候选。

D中，Q和缓存K均为动态量，不是静态W8权重；FFN随机矩阵的质量与能耗不能直接迁移。点积误差可能改变候选排名，全部历史K扫描仍在。

E不能将“单头Softmax保持排序”推广成“四头raw score求和等价”；F则需防止再次引入串行更新和长预热。

## 7. 最小对照与实验顺序

### 7.1 首轮只固定权重做推理

沿用同一原始后训练模型，FFN、Norm、Q/K/V/O等均不更新，避免用训练差异解释筛选收益。模型、tokenizer、原文与目标位置SHA先核验，并重跑匹配BF16。

| ID | 粗筛候选生成 | 第一轮下游 | 回答的问题 |
|---|---|---|---|
| D0 | 原SparQ256：准确粗Softmax、概率和、Top-k | 准确候选Softmax/PV | 当前基准 |
| D1 | 准确粗Softmax＋数字IID混合采样＋A的去重/cap | 同D0 | “采样选集合”本身是否可行 |
| W0 | P8赢家保持＋A的去重/cap | 同D0 | 量化、有限链和相关性增加多少误差与费用 |
| Q0 | P8各头odds分布直接IID＋相同去重 | 同输入的行级诊断 | 区分P8分布偏差与WH有限轨迹 |

D1应采用均匀选头再按该头类别概率采样；其recent、去重、停止、cap均与W0一致。它不是数字Top-k的等价实现。

Q0不是部署实现，不为它宣称便宜的真实电路。若评估B2，另建符合其head/mask/rebase规则的数字对照，不继续使用A的D1冒充算法匹配。

### 7.2 先行级，再小模型评分，再完整WT2

1. **CPU机制检查**：手工小N、均匀/单峰/多峰、四头峰值互不重合、近期质量集中、P8支持不足、padding/短上下文、所有cap失败路径。均匀跨批仲裁、保持记录、候选唯一性和无未来访问需独立oracle。
2. **真实行诊断**：先用TRAIN及独立VAL，在全部36层和8个KV组覆盖真实粗分数，比较D0/D1/W0/Q0；`M_cap=256/512/1024/2048`只在这里探索。已有P8结果来自精确QK，不能代替本次粗QK检查。
3. **短后缀模型预评估**：只带入少量已冻结工作点，至少3个部署seed；检查候选计分覆盖、因果KV轨迹、实际完成率及耗时。短后缀PPL明确不叫完整WT2。
4. **完整WT2**：通过机制与容量门禁后，使用window2048/stride1024、原文无chat模板、相同目标ledger；全部计分目标和36层覆盖。重新核实token/位置SHA，不照抄历史目标数。每个随机配置分别算完整PPL，再报告三seed均值与样本标准差。
5. **联合概率Attention**：对入选粗筛接同一后级P8赢家保持，固定同一`S_v=128`作首次联合比较；对照仍保留原SparQ256＋同后级。若要扫`S_v=32/64`，另列部署扫描，不混成粗阶段`M_c`变化。
6. **硬件评估**：先事件与容量账本，再对少数有质量希望的配置补同工艺/同资源比较。GPU仿真耗时不作为ASIC时延或能量。

本文件是上述执行安排，没有据此提交CPU/GPU或EDA任务。现有已看过的WT2 test不宣称blind；参数选择留在TRAIN/VAL，test用于配置冻结后的报告。

### 7.3 必报质量和容量指标

- 完整WT2 PPL及相对D0、匹配D1的变化；不将行级TV或heldout CE直接改称WT2 PPL。
- 各Q头准确教师注意力质量保留、漏选质量、同输入候选V输出误差；报告层间和低分位尾部，不能只给组平均。
- `K_c`、`K_free`、可达支持、补满率、实际候选数、实际`M_c`均值与P95/P99、cap失败/短上下文比例。
- 保持/切换、重复、近期命中、候选集合稳定性；不得将重复观察从预算剔除。
- GQA四头共享候选的真实K/V地址并集、burst/布局/缓存条件、实际读取字节。

PPL容差和容量要求在执行前明确填写；目前没有用户批准的具体百分比，不能自行把某个损失认定为“可接受”。有固定K失败的配置不能通过删失败行生成完整质量结论。

## 8. 硬件复用与公平成本

### 8.1 粗阶段不等于256节点后级

粗阶段面对`N≈2048`个位置，而后级只有256候选。若仅有256节点资源，一次粗WH全位置更新至少涉及约8批，且四头各有自己的阈值和赢家状态。

分批必须保持一次全局WH更新的数学含义：当前赢家提议、全局是否存在活跃位置和全局均匀仲裁都要正确。可采用活跃计数加权或流式reservoir；不能均匀选批、取第一个有1的批、或在每批结束都更新赢家，这些都会改变算法。

### 8.2 分开记录节点活动与时钟

若按需推进被抽中的头，四头各预热`B_c`，粗阶段节点提议数近似为：

```text
粗p-bit提议数 = N × (4B_c + gap_c × M_c)
```

例如`N=2048、B_c=32、gap_c=1、实际M_c=512`，为1,310,720次节点提议。该数字是工作量算例，不是测量或芯片时钟。

若每轮四链全更新但只取一个头输出，工作量则约为`4N×(B_c+gap_c×M_c)`。两种调度不能混账；保留多少并行阵列、随机端口和仲裁器应与时延/面积同时注明。

需要计入：

- D1的准确粗Softmax、CDF/alias等实际采样准备、数字RNG、抽样、去重及补满费用；记录具体实现与数制，不将IID抽样视为免费oracle。
- 数字选维度、温度、粗QK、全历史K读取。
- signed12分数存储/转换、扩位求差、U8驱动与LUT配置。
- 四链冷启动、预热、间隔、保持、独立R8供给、无偏头选择及全局仲裁。
- 去重位图、候选地址压缩、补满反馈、cap检测、mask/rebase和状态切换。
- 候选完整QK、后级采样、V读取/累加，以及两个阶段复用阵列时的重新配置。
- SRAM/DRAM实际事务、端口、缓冲、互连、背景与空闲能量；不能只按逻辑元素数估带宽。

2K去重位图约256B；256条11位地址约352B。四头各2K个8位阈值为8KiB，四头12位分数为12KiB；是否同时保留和怎样复用须按实现说明，不能全部视为免费寄存器。

现WH参考要求候选间提议符合其独立性合同。复用FFN共享字或GF线性扩展会改变联合规律，需另做质量验证，不能只检查单bit直方图。

### 8.3 现有数字参考是什么

当前数字筛选已采用exp查表、公共倒数以及radix直方图/阈值选择，不应把对手设置为未经优化的浮点exp黑盒。

旧K128专用逻辑参考如下：[来源6]

| 选择器/归一化并行度 | 55nm等效面积 | 组合能量/KV组 | 独立工作周期@100MHz |
|---|---:|---:|---:|
| 4/4 | 0.026404mm² | 36.419nJ | 9800 |
| 16/4 | 0.038446mm² | 32.618nJ | 7316 |
| 16/16 | 0.086235mm² | 29.603nJ | 2708 |

这是128候选（96非近期＋32近期）的前布局模块PPA派生组合，只含选择器和粗归一化/GQA合并；不含QK、温度/转换、SRAM/DDR、V。它不是新K256完整PPA，也没有与本次采样方案匹配PPL。不能按候选数或采样数比例缩放后冒称新电路结果。

在2K/4Q/r32/d128/K256下，粗QK约262,144 MAC/KV组，候选完整QK约131,072 MAC（尚未扣已读维度复用）。因此，即使粗Softmax和Top-k都被替换，粗点积和扫描成本仍可能占主要部分。
