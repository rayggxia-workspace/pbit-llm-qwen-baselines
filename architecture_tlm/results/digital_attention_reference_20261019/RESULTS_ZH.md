# 数字 Attention 解析参考

单 token decode；24 层 QKV/RoPE/KV/QK/online Softmax/PV/Wo。概率和PV累加为FP32。
本程序只核对工作量、容量和资源速率边界，未运行模型、RTL、综合或功耗仿真。
时间为资源下界或假设的串行计算阶段之和，不是已实现端到端延迟；两者不相加。
完整能量/面积/功率为 null。SRAM面积和内部流式读写能量仅为有来源的局部项。
