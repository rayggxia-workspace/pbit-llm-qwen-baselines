| ID | 算法与实际实现 | 输出整数与周期 |
|---|---|---|
| S0 / mode0 | 当前精确加权树原字节副本，T32、三级、无ICG | 原始同事件和；32拍采样再排空 |
| S1 / mode1 | 13个有效幅值位平面的正负popcount差，13位有符号时间计数，最后平衡树恢复位权 | 与S0同事件逐位一致；采样后1拍恢复 |
| S2 / mode2 | N个6位事件计数共享M列，随后MSB先行6拍Horner精确加权 | 与S0同事件逐位一致；32+6拍，后端计入 |

N64/M1、M8，权重7位幅值+符号[-127,127]，输入单独符号、bin0/1/2/3对应左移6/4/2/0，无效bin贡献0。SC结果不除T，D0/D1输出为q∈[0,256]的分子点积；T32期望参考为数字整数除8。D0/D1不承诺与一次随机采样的整数结果相同。统一32位输出，范围推导保留；S2计数含端点32，不能只用5位。这里的q9是已有量化接口，不含BF16编码成本。

配置和权重驻留外部，frame握手至out握手保持不动；事件仅在sample_valid&&sample_ready时消费，采样后停止接收，结果在回压时保持。不能交换OR与时间累计。v2在S2/D1后端非工作阶段隔离乘法选择输入，避免计数期间宽树无用翻转；v1功能执行包保留，不原地覆盖。本轮核心全为时钟使能DFF，没有将CE冒称ICG；胜出方案可再做真实门控对照。存储/RNG/比较器/真实广播线、BF16编码与最终尺度转换、CTS/SDF/SPEF均在当前边界外。
