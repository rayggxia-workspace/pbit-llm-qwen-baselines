# Issue186：成熟调度的借鉴与共同资源对照（进行中）

本文件随实验补全。目标是把已验证的随机 FFN / Attention 算子接入明确的存储执行规则，并给普通数字算子同样的调度机会。不是把第三方模拟器的名称当作精度证明。

## 固定边界

- 模型形状：Qwen3-4B 后训练模型；36 层，batch=1，已有 2K / 8K KV 的单 token decode，包含 embedding、归一化、投影、残差和 lm_head。没有模型权重推理、PPL、prefill / TTFT。
- 共同主资源：100 MHz core；8 MiB 片上 SRAM、64 bank、64 GB/s 共享接口；DRAMSys 的双通道双 rank DDR4-1866、16 GiB、32 个在途 burst。SRAM 宏采用已有 55 nm SS 表征，互连宽度与 STA 仍是宏假设。
- 最新 FFN 保留固定四档、分层短流、P8 随机非线性、AND 输出直入固定 W8 的契约；此次改变调度，不改数值算法或重训。
- 主对照同时保留 BF16 FFN 与 W8 数字 FFN；W8 是最重要的隔离对照，避免把权重字节减半误当成随机计算本身的收益。数字矩阵 512 MAC/周期仍是可调宏参数，不能声称为实测 GPU / 最优 INT8 ASIC。
- Attention 对比准确路径、筛选后准确 softmax + PV 采样、筛选后校正拒绝采样。使用实际集成随机服务；输入为有版本的合成 logit，不能据此证明模型质量。

## 调度结构

```mermaid
flowchart LR
    D[标准 DRAMSys\n32 个 burst 信用] --> P[共享 SRAM ping/pong\n有限容量与复用时间]
    P --> L[本地 operand / weight tile\n有限容量]
    L --> C[数字 MAC 或随机 FFN\n各自延迟与 RNG 依赖]
    C --> R[归约 / 编码 / 写回\n释放 tile]
    R --> P
    A[筛选与采样地址] --> G[排序去重 + SG 描述符\n最多 256 个 span]
    G --> D
```

每一个 tile 都要经历发起 DMA、到达共享 SRAM、本地装载、执行和释放。下一次 DMA 可以覆盖本次计算；缓冲未释放时不能覆盖。普通数字和随机算子共用这一生命周期，但保留各自的数据宽度、累加、非线性和随机源的真实依赖。跨算子 / KV head 仍按既有保守顺序执行，未声称全局乱序最优。

零散 KV 读取通过一个有界 scatter-gather 描述符进入现有真实 DRAMSys bridge。在同一个描述符内，32 个 burst 信用可以跨 span 滚动；不再每遇到一个不连续地址就强制等待整个前段结束。地址、字节和 burst 数均逐项校验。描述符形成每 span 暂计一个 core 周期；256 项 × 16 B = 4 KiB 控制存储显式记账，PPA 未知。

## 公平性与证据约束

1. 固定资源对照先使用相同容量、带宽、DRAM、buffer 生命周期；然后对两类算子使用相同的 tile 候选集合。并行阵列数量扫描单独列出，因为增加阵列不等于相同面积。
2. 算子逻辑活动与传输字节需守恒，不能靠省掉恢复、部分和或采样失败获得加速。SG 只改变提交方式，不减少必需字节。
3. DRAM / RNG actor 的时钟只能向前。此次不把未来完成的同步 DRAM 请求回填到过去，也不偷偷推测一个尚未发生的随机采样结果。
4. 能耗只报告已定价子项和未定价清单。DRAMPower core_limits 现存负 ACT 项保留原值并单独提示；不把它当物理负能耗，也不把不完整能耗相加宣称整芯片能效。
5. 上游 ONNXim 原生 probe 和我们的全模型 TLM 分开列证据。小 probe 匹配不等于整个 Qwen 已经在 ONNXim 上正确执行。
