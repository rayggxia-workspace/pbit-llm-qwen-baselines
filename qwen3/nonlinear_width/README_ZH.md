# Qwen3-4B非线性位宽初筛（Issue171）

后训练Qwen/Qwen3-4B，revision与模型文件沿用已验证PR160/169。独立于训练计划Issue159，未训练、未修改历史快照。目标是先估计g/u接口和sigmoid驱动/概率需要几位。

所有36层FFN、原准确SDPA Attention。新跑BF16；W8确定权重参考，矩阵FP32恢复暂保留以隔离非线性数制影响。TRAIN 16段×512token，在W8和固定四档T64路径校准每层每64通道g/u最大值，向上取PoT。固定x/z表复用Issue168并核SHA；测试不调整任何范围。

测试为16段×128=2048目标后缀PPL，每段2048前缀，batch1，前缀也经过全部替换层；不是完整WT2。18项确定矩阵配置：未改非线性参考；g/u幅度6/7/8/10/12；sigmoid驱动8/10/12；概率6/8/10/12；组合6/8/8、8/8/8、8/10/8、10/10/10、12/12/12。另在固定四档T64/K64矩阵背景下，对未改非线性、8/8/8、10/10/10各测3seed。加BF16共28项。

幅度位数不含独立符号，无true-one，q/2^b最高为1−2^-b。7位幅度+符号可对照总共8位的对称signed8可表示集合。sigmoid输入是总共f位的有符号码，步长32/2^f、范围[-16,16−步长]。概率输出q/2^p，额外true-one端点。均采用nearest-even舍入、饱和。LUT在设置阶段用float64生成并冻结，前向组合路径只查表；结果记录LUT SHA。

**本轮非线性只评估三独立流AND的条件均值**，不采样AND事件。量化后的g/u及概率都是有限dyadic值，组合乘积用FP64计算后明确转FP32接回旧down oracle。没有声称实现整个定点FFN或替代硬件乘法；单因素的理想sigmoid/未量化概率仅用于误差归因。短采样方差、实际PRNG、跨tile有限累加、物理响应、PPA均不在本轮验收。不能把良好均值PPL解释为32/64拍三流AND已通过。

功能测试：幅度端点/舍入/截断、全部LUT地址与独立标量公式、比较器端点、三流枚举期望、小模块前向。Slurm复用只读环境/模型，不在登录节点运行GPU。
