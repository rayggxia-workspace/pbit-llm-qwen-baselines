# Attention与FFN数字p-bit能量口径核对

2026-10-31，rayggxia，接续Issue204/PR219；只读Issue198、Issue95原件，不改变其源码/状态。离线重算已有PPA，没有新EDA、模型、PPL或硬件run。

结论：没有发现J/pJ/fJ换算或比较器面积的数量级错误；两边原先的“最好”并非统一的能量最优结论。GF64是低成本随机供给候选，共享LUT省面积；共享LUT是否省每比特能量还取决于保持周期、时钟门控和加载调度。Attention最新完整实测与本次FFN都表现为：共享LUT面积更小，但当前完整事务能量略高或明显高于全LUT。

## 统一分母和边界

`E_bit = P_window × t_window / N_consumed_bits`，1pJ=1000fJ=1e-12J。面积只对本项目raw乘0.81一次，能量不缩放。

- FFN单个Sigmoid流：N64/T32，每帧2048个Sigmoid比特。g幅值、u幅值还各有一路比较器；三路AND后只有2048个z比特，不能把6144个比较器输出当6144个z。8列Wd复用同一前端，不能再把分母或前端成本乘8。
- Attention：N128/S128，每查询16384个被消费的候选比特，最终只有128个被选索引。候选位、赢家索引、原始PRNG位和独立有效样本的分母不同。
- 本文数字p-bit表示按概率产生的候选位，不表示已证明IID的熵位或ESS。GF64的跨路依赖和模型质量门禁保留。
- 共同SS1.08V125℃100MHz，但LUT函数、刺激和负载仍不同。FFN为signed8/F3原g表；Attention为U8 gap/F4负驱动表。Attention外部输出2fF、FFN1fF；均为零延迟门级/前布局，有原报告功耗告警。

## Attention实际并没有证明共享LUT能量最优

|---|---:|---:|---:|
|2GF64＋4LUT＋128×q8＋128比较器|2.166927|0.05293444|249.458|
|2GF64＋128LUT＋128比较器|2.140116|0.07235412|217.458|

4LUT方案每32节点共用一表，面积少26.84%，但每查询能量高1.253%。因此它是面积/资源候选，不是这两个配置中最低每查询能量者。原报告未把两种方案称为同质量PPL结果。

完整2.166927nJ除16384得到132.26fJ/内部候选位的归一化价格，除128则是16.9291pJ/选中索引；二者都不是纯Sigmoid采样核的能量。完整路径包含FP32转换、分数保持、max、候选源、独立公平源、仲裁、赢家保持和直方图。旧综合把Sigmoid/比较器与其他逻辑展开，不能从总数直接精确剥出纯p-bit价格。

## 概率保持和时钟门控确有实现差别

本轮从Attention原始cell_power/inventory重新分组核验6个工作窗口、142815行单元：

|项目|Attention共享4LUT|FFN共享2LUT＋ICG|
|---|---:|---:|
|节点/每配置采样次数|128/128|64/32|
|概率状态|1024bit|512bit|
|概率ICG数量|32|64|
|每颗概率ICG覆盖|4个8位字|1个8位字|
|概率DFF＋ICG，每节点一整次配置及保持pJ|0.704398|0.773859|

同一节点配置的缓存/门控总费用约0.70和0.77pJ，数量级接近；但FFN只摊32次，Attention摊128次。两者ICG粒度、复位DFF、写口和工作时长也不同，不能把24.18/5.50直接当相同8位寄存器的单位能耗错误。

Attention的4个LUT同拍写入连续4字，综合能把它们用同一门控驱动。本次两个LUT各写一个32路组，显式每字一门控，采样时虽已关掉下游DFF时钟，64颗ICG的根时钟仍翻转。可把同拍写入的两字改成一个16位门控组，或另研究批量写入/更粗门控；不能不改写口/保持逻辑就假定可直接白得4字门控收益。

本次Wd时钟在共享查表的32拍中仍运行，Attention则对更多状态使用实际ICG。加权Wd整帧436.6733→566.6100pJ，增加129.9367pJ；其中Sigmoid命名单元增40.0332pJ，其余约89.9035pJ在幅值路径、Wd、控制及新增等待内。不能把整个差额都归给数字p-bit或都归给纯时钟。

## GF64也必须采用同一模块边界

Attention当前紧凑候选源是两颗32位状态＋组合GF映射，各提供64个R8端口；共64个状态DFF，另2个装载控制DFF，没有1024位随机字输出寄存器。已测候选源单元归因约387.924pJ/查询，即23.677fJ/候选R8，约2.960fJ/原始随机字输出bit；不能把后一个数当完整p-bit价格。

FFN436.67/566.61pJ集成结果中实际GF64仍在核外。旧服务端点含checkpoint/握手/比较/输出等，不能拿端点整价当裸GF64，也不能叠加端点后再收一次比较器。将这里23.677fJ代理加到FFN命名价格，可得全LUT约40.55fJ、ICG共享约60.09fJ/单Sigmoid位的条件块和；它不是新集成测量，跨路质量、T32推进、实际广播负载及三个随机前端必须另验证。

因此本轮修正的是结论的适用范围：共享LUT省面积、GF64省随机供给成本；不能据此推出在T32冷加载和当前门控组织下共享LUT必然最低J/bit。下一项有针对性的实现工作是写口对齐的更粗概率门控、查表期间Wd停钟，以及明确32/128次保持的配对表征；本轮未启动这些新EDA。
