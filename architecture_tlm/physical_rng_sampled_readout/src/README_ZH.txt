下一轮：单通道真实比较器定时采样 / Issue184、PR185 / sampled_readout_v1

边界：原零外加电容2MOS噪声核心＋已实测LVT20u连续10MOS比较器＋13MOS传输门/再生保持锁存＋5fF输出。
共25MOS，不是全阵列。原比较器输出5fF保留，锁存输入负载真实接上；不修改PDK或38387635执行快照。
13MOS包括输入/反馈两个传输门、交叉反馈反相器、两级输出缓冲和实际复位MOS。
所有比较/保持均由真实工艺MOS完成；外部时钟/复位、偏置电压/电流为理想台架源。
不声称时钟树、DAC或偏置发生器的面积/能耗已实现。

固定时序，每1us读一个bit：
  读出时刻 t=k*1us。
  采样关闭（track下降50%点）在 t-50ns。
  跟踪窗口100ns，即 t-150ns到t-50ns。
  输入关闭后2ns，接通再生保持反馈；留到t总共50ns的关闭后再生时间。
  每个理想控制源有1ns边沿，互补的两相控制留2ns死区。
  读出后在保存点检查Q保持到t+800ns，下一跟踪从t+850ns开始。
  复位MOS在启动时拉低存储节点，100ns后释放；正式启动段固定2ms，不看结果挑删除段。

Vref沿用38387635独立校准冻结的0.604745V，parent_reference.json保留原字节及SHA。
不对本轮验证seed重校准。TT25C、1.2V、noisescale1、500Hz/100MHz、maxstep2.5ns。

任务顺序：
1. 两个真实通道确定性输入阶跃（1/10mV）检查固定采样点、正确性和保持。
2. 锁存单元输入切换相对采样关闭时刻±20/±5/±1/0ns，正反方向各一遍。
   这是用理想电压刺激锁存单元的边界诊断，不是用理想比较器替换正式噪声通道。
   >=5ns稳定输入必须通过；近边沿结果保留，不把20us扫点当罕见亚稳态失效率认证。
3. 三个新numeric seed66007/66013/66029，3.0001ms短记录，比较2.5/1.25ns步长及100/200MHz带宽。
   先要求Q/Qbar采样/保持保存点无无效电平，再按预设均值容差检查P1/ACF；属于工程筛查而非严格收敛。
4. 只有前三步通过且外推不超剩余6h预算，才启动新seed68003/68011/68023各20000次正式记录。
   每条22.0001ms总时长，实际取2ms..21.999ms的1us读出点；捕获边沿在各读点前50ns。

重要统计口径：
  同时保存核心、比较器、Q、Qbar、跟踪控制。正式长记录保存间隔50ns，内部maxstep仍2.5ns。
  sampled_1us.csv含capture时核心/比较器电压、采样边沿、读出时间、Q/Qbar和有效性。
  比较器捕获时为MID也保留：只有实际Q/Qbar是否在读出前达到互补有效电平才决定读出是否通过。
  Q无效点不删除；VN/all包也保留其invalid标记，禁止用模拟电压oracle筛出好种子后称硬件通过。
  分seed输出P1、多lag、分块漂移、保持、VN和32/177bit种子包统计，真实时间戳保留。
