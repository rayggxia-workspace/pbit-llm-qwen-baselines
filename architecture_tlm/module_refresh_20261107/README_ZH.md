## FFN：真正更换了什么价格

100MHz不再沿用旧T64/C20核价。新C19完整M128面积1.306552mm²，GU16功率18.0667mW/180ns，Wd32功率9.814mW/340ns；停钟等待参考2.267mW（seed17）。一帧含128个DOT64，面积已raw×0.81一次。计入核内GF64/SNG、非线性、准确归约、双结果保持和518个ICG，不重复收随机源价；SRAM/编程/跨K/生产转换/DRAM另计。

同输入C20配对表明：仅C20→C19使面积少0.299%、GU能量少0.733%、Wd少1.075%，不能声称少一位就整核省5%。旧原生6/8核时间差仅0.0266%，支持维持6核，但那批旧QK/PV资源快照不冒充当前整机结果。

计费采用“活动gross能量＋非活动驻留等待”，等价于“活动增量＋全驻留背景”；不能gross再加同一段完整背景。250保留空PPA字段和明确的旧T64参考情景，收到同PVT/短T结果后可通过同一profile接口替换。外部20位结果传输、跨K64位及4/3拍量化/恢复合同不变；g8是G/8补码，u8是独立符号加7位幅值，不能混为相同编码。

## Attention：改变了执行与布局

QKV/O/lm_head从整tile读/计算包络改为有限FIFO供数，信用同时覆盖在途和已返回未消费数据，最后一次FMA消费后才回填。固定投影权重必须部署前打包为`[Kblock8][outputRow][8BF16]`；每16B仍是同一输出行连续8个K权重，推理不额外转置、不增加外存字节或SRAM端口。FFN权重布局不改。

继续公平bank仲裁。新分数路径为FP32 max→max-score→RNE/sat unsigned8/F4→floor sigmoid LUT→P8阈值→R8比较。每头两遍实际SRAM读替代旧准备65拍；250取消另加的5.2µs和额外SRAM读能量预算，不重复计价。73拍是无争用宏合同，实际仍有端口/信用等待，不是新STA或PPL结果。

## 本次验证与面积边界

100MHz：相同seed17、完整冷第0层（含embedding，无lm_head，36层地址分配），解析外存136.4606GB/s/30ns：旧16KiB配置1.19475ms，新1.20762ms，+1.077%。算术/采样量、外存字节及地址sum/xor一致，队列排空。新增有限供数使模型更具体，不把它描述成加速。新FFN核的全层驻留能量约0.041518mJ，只是核心池，不是完整FFN或整片能量。

已覆盖面积小计33.76037mm²，含10KiB FIFO代理0.49533，已替换C19核价；新宽分数前端另按8组×4个FP32加法器等级单元＋保持/控制给0.38556mm²宏预留，含预留约34.14593mm²。旧sampler准备部分尚未切分，保留旧整块面积，可能存在残余重叠；不是34.15mm²流片面积结论。FIFO捕获按事件计费、选择暂取2倍捕获；门控空保持不收动态，泄漏/控制/互联仍待标定，不写成物理零成本。

250MHz：采用16KiB返回保持后，3/2核完整冷单层解析回放分别1.085980/1.114144ms；相对24KiB仅差1～3拍，算术/采样和外存地址一致。3核面积覆盖代理22.59477mm²、2核21.62529mm²，其中短T核仍为旧TT250 C20面积参考；短T实测能量保持null。仍不是完整36层原生LPDDR结果，原24KiB对照与SHA保留在DMA16交接。

250接合暴露父事件循环1e-6ns容差与模块1e-7ns间隔断言不一致：296591.9999996155ns的近边沿触发曾失败。宿主新clock_bridge按整数4ns周期审核并保留父容差；同周期重复服务和真正离边沿事件仍拒绝。3核238272次tick无离边沿，最小周期间隔1；2核也通过。原私有模块和运行任务未改，失败诊断保留。
