# 第一轮55nm FFN校准包：计数与整数恢复

**先跑2个小配置，查看时序，再决定是否扩展。** 这是给DC/STA使用的独立包；随机源、SRAM、非线性和BF16转换均不在本轮边界内。正式任务 [Issue193](https://github.com/rayggxia-workspace/pbit-llm-qwen-baselines/issues/193)。

## 要回答什么

旧版有若干算子在100MHz下负slack，不能把“RTL一拍写完”当成“工艺一拍做得完”。本包用寄存器把精确计数和整数恢复拆开，测清：每拍能接受多少输入、输出要等多少拍、对应面积多大。综合后先核验时序；确认可用后再用代表性活动跑功耗。尚无本包55nm综合、STA或PT功耗结果。

| 文件/入口 | 用途 |
|---|---|
| `RUN_FIRST_ZH.md` | 上服务器后先做哪几步 |
| `rtl/ffn_counter.sv` | 64路二值事件×固定8位有符号权重，精确分档计数 |
| `rtl/ffn_restore.sv` | 各档按二次幂对齐、整数系数恢复、舍入 |
| `rtl/ffn_accumulator.sv` | 64位本地部分和；饱和、溢出标志及输出回压 |

| `tests/run_all.py` | 独立整数参考＋逐周期握手验证；Icarus或VCS |
| `flow/` | 55nm DC、STA、Slurm提交、结果检查脚本 |

## 数据怎样流动

`64路采样bit → 符号/权重门控 → 6级平衡精确加法树 → 每档时间计数 → 分档对齐和恢复 → 本地部分和寄存器`

- 权重为7位幅度加1位符号，范围−127～127；不是把−128偷偷按同一格式使用。权重由外部保持，本模块不复制一份权重寄存器。w_mag7、w_sign、x_sign及bin_id须从frame接受至输出接受保持稳定；x_sign为0表示正、为1表示负。
- 每一拍，每个输入只给一个0/1事件；PRNG和比较器由外部提供。没有保存完整的64/128拍比特流。
- 4档或7档使用独立有符号计数，64拍计数器宽20位，128拍宽21位；档位接口统一3位。**本包全部精确计数，没有OR近似。**
- 计数结果按照各档的二次幂对齐，再乘一个16位无符号整数系数并右移，采用就近偶数舍入；最后进入64位饱和部分和。
- 当输出接收端堵塞，结果保持不变，不会重复累加。复位是同步低有效，时序脚本不豁免复位路径。

恢复合同为 `S = Σ count[b] × 2^[2(B−1−b)]`、`delta = round_even(S × coeff / 2^rshift)`。B4相对移位为6/4/2/0，B7为12/10/8/6/4/2/0。它提供可综合的整数数据通路；**真实模型的公共尺度、权重尺度和1/T怎样编译为coeff/rshift，还需要算法数值对齐和PPL验证**。本包不声称已替代当前模型的全部恢复运算。

## 周期怎样读

以下是无阻塞的RTL寄存器/握手合同，需由STA确认目标时钟可达后才能换算时间。

| 模块 | 延迟 | 连续接受能力 |
|---|---:|---:|
| 64路计数归约 | 输入采样被接受后6拍进入计数器 | 每拍1组64路bit |
| 4档恢复 | 接受输入到最早输出握手8拍 | 无回压时每拍1个恢复事务 |
| 7档恢复 | 同上10拍 | 同上 |
| 本地64位累加 | 1拍 | 无回压时每拍1个delta；反馈路径待STA |
| 4档64拍完整链 | 接受frame后80拍可握手输出 | 当前校准壳仅允许1帧在途 |
| 7档128拍完整链 | 同上146拍 | 同上 |

计数器本体的 `out_valid` 在最后一拍输入之后6拍置位；下游最早在下一边沿接收，因此不能把所有“valid出现”和“握手完成”混在一起加减。本包测试既覆盖无阻塞时延，也覆盖人为阻塞。M8只用于计数核面积扩展测量；恢复与累加保持单通道，不能把这个校准壳的吞吐当作完整FFN或整机速度。

本地功能验证的M1计数核使用3个确定seed；M8扩展配置使用1个seed、9个完整帧和极值/复位/回压检查，目的为RTL功能验证，不是PPL随机误差统计。旧Icarus宽并行仿真较慢，240秒超时原件保留，正式runner上限900秒；超时本身不代表数值或工艺时序失败。

## 本轮如何迭代

1. 先看功能、PVT、约束、未约束路径、setup/hold及关键路径，不只看“工具结束”。
2. 如果计数树通过而累加反馈失败，改反馈结构或降低该模块接受速率；不能仅凭加一个输出寄存器解决反馈路径。
3. 如果恢复的乘法、移位/舍入失败，按报告增加相应流水级，重跑同一整数oracle与握手测试，更新TLM latency/II。
4. 保留旧结果与失败记录。时序稳定后再用相同源码、代表性翻转活动提取PT功耗，记录有效结果数和窗口，避免空闲时间稀释能耗。

面积为综合标准单元面积，尚未含SRAM宏、PRNG、比较器、物理布线/时钟树，也不等于芯片面积。100MHz是首轮目标，不是保证。
