# 统一250MHz Attention交接

用户明确计算、SRAM、DMA前端统一250MHz；此版本取代旧计算250/SRAM100候选作为250MHz接入入口。原100MHz和旧混合时钟执行原件不改，整体TLM默认尚未替换。

保持K128/S64、B1/N2048、32Q/8KV、1216KiB/304bank/16B/1RW和24KiB返回保持。LPDDR5X derived8533与136.4606GB/s标称带宽不变。内部fabric保留320个16B字/拍、DMA保留24请求/拍；每bank仍一拍至多一读或一写，未增加端口。

交接继续选256FMA/64PV ADD/4top+4norm/4采样/16归约/5KiBQK暂存；三seed均值589.437µs。320作为偏时延备选；192的资源/时间另列，不因SRAM升频直接改成192。

面积已乘0.81一次。13.61588mm²包含整个共享普通池、Attention逻辑、512KiB Attention＋160KiB权重SRAM；全部公共DMA/向量等支撑也归属时17.21316mm²，整机只能计一次。本轮只改时钟不改容量/宏/数据通路，面积预算不变，新增CTS/布线成本未测。

SRAM按实际读写次数乘既有10.0527/13.9599pJ，漏电按实际时长计；不把单次能量乘2.5。SS1.08V125℃caseE库提取最小读/写周期3.468/3.4271ns、CLK到Q2.8767ns，支持4ns作为模型周期；仍不是新TT250功耗或控制器/布线签核。时钟树/外部驱动、CEoff残余未测项保留。

片上能量略随执行时间缩短下降，但同一工作更快完成，平均功率上升。外存能量保持4/6.6/8pJbit敏感性，未计未知刷新/PHY背景。先前100→250片上约+14%～16%的粗估基于混合时钟时延，不能继续用于本版本；尚无完全同口径100/统一250整体配对。

采用model.install前宿主仍由冻结100MHz模板构造，安装必须在任何预取/事件前完成；安装后common_period、mem.period、issue_period和model.clock统一4ns，旧宏按原周期数换算。run_layout.py为独立入口，执行源及runtime/inputs依赖和原件SHA由私有提交索引保留。宽分数前端另留5.2µs，未加进本表原生时延；PV2、微块暂存、根门控仍有明确代理。无新RTL/PT、PPL、完整token或256冷lm_head。

5项原生LPDDR模块回放、1项解析门禁，4ns边界、输入SHA、同seed算术/采样/唯一V、SRAM字事件及DRAM字节/地址摘要守恒、有限队列/资源租用检查通过。下一步容量扫描单独做，不能直接将SRAM按2.5倍缩小。
