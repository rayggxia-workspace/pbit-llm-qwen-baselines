# 28 nm / 250 MHz 三模型 decode 时间、能量与功率

概率版含 `lm_head` 的延迟分别为 **Qwen3-4B 51.13、Llama-3.2-3B-Instruct 43.93、DeepSeek-LLM-7B-Chat 98.98 ms/token**。相对 W8＋SparQ、准确 PV，概率版快 1.51–1.67 倍，片上每 token 能量低 20.7%–22.9%，含外存后每 token 能量低 2.27%–2.45%。

三模型使用同一套 TLM 配置：28 nm TT、0.9 V、25 °C、250 MHz、batch＝1、上下文 2048 token、832 KiB SRAM，使用同一 LPDDR 与 DMA 配置。新增的 15 项完整运行均已通过 Slurm 和封存核验，表中另列入此前已核验的 Qwen 概率版三次运行作为对照。

含外存能量按外存事务量和 **4 pJ/bit** 估算。平均功率＝每 token 能量 ÷ 每 token 延迟，`mJ/ms = W`。概率版的时间和能量为三个 seed 的均值，平均功率以这些均值相除。面积为 TLM 已计价的片上硬件面积。

## 与 W8＋SparQ、准确 PV 的比较

按含 `lm_head` 的结果计算。概率版计入面积为 **6.480 mm²**，该数字对照为 **6.399 mm²**，相差约 1.26%。

| 模型 | 概率版加速比 | 片上每 token 能量降幅 | 含外存每 token 能量降幅 |
|---|---:|---:|---:|
| Qwen3-4B | 1.67× | 22.92% | 2.45% |
| Llama-3.2-3B-Instruct | 1.52× | 21.28% | 2.27% |
| DeepSeek-LLM-7B-Chat | 1.51× | 20.66% | 2.40% |

三个模型的外存能量都占大头，因此含外存后的节能幅度小于片上。概率版在更短时间内完成一次 decode，所以即便每 token 能量下降，含外存的运行平均功率仍高于对应的数字方案。
