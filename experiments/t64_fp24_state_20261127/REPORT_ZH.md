# FP24跨块部分和：真实T64小测结果

2026-11-27，Issue225 / PR266，Slurm62265已COMPLETED/0:0，耗时6分59秒。

**结论：FP24值得作为32位定点的下一项候选。在本次真实累加链中，FP24比24位定点明显准确，Wd最终BF16变化也少于32位定点；GU仍以32位定点更准确。BF16逐块状态累加明显偏粗。**

## 一眼看结果

所有数制重放相同tile计数和完整K顺序。相对误差采用整体相对RMS，即误差向量二范数除以参考向量二范数。

|跨块状态|GU相对RMS误差|g/u成对编码改变|Wd相对RMS误差|Wd最终BF16改变|
|---|---:|---:|---:|---:|
|32位定点|0.000114%|2/27,648，0.0072%|0.00717%|512/36,864，1.389%|
|**FP24，E8/M15**|**0.00358%**|**34/27,648，0.123%**|**0.00461%**|**8/36,864，0.0217%**|
|24位定点|0.0579%|4,304/27,648，15.57%|1.893%|33,993/36,864，92.21%|
|BF16部分和|0.847%|21,926/27,648，79.30%|0.486%|31,878/36,864，86.47%|

编码/BF16改变比例表示数值位模式变化，不是准确率或PPL下降比例。所有浮点转换和累加均**零溢出、零非零下溢清零**。FP24的g/u符号与尺度指数在本样本中均未改变；g/u概率码分别改变25/9项，sigmoid输入地址改变4项。

FP24对GU的整体误差约比24位定点小16倍，对Wd约小411倍。相对32位定点，FP24的GU误差较大、Wd整体误差较小；它不是在所有指标上都更优。例如Wd最大绝对误差FP24为0.27661，32位定点为0.10547，体现了浮点与固定绝对单位的取舍。

## 测了什么

- Qwen3-4B、T64训练100M导出、W8；GU16/Wd32，x/g/u组64共享PoT基准＋逐元素S/S2，准确Attention，seed101。
- 原模型的真实128-token前向，覆盖全部36层。每层抽取token位置0/1/64/127；GU取3对完整g/u通道组（共384列），Wd取首尾两个128输出组（256列）。共72个投影样本、55,296个GU值和36,864个Wd值。
- 每条链覆盖全部GU40/Wd152个K64块，保留真实顺序。CPU整数重放与原GPU整数输出逐位一致，再比较各数制。
- FP24为E8/M15，16位有效精度；BF16为8位有效精度。每个tile转换时RNE一次，每次状态更新再RNE一次。没有用FP32长累加后只在最后截位。float64只承载每步已舍入的目标格式值，288条真实链另以Fraction精确分数独立复核。
- 定点24/32使用与现有窄状态候选相同的元数据保守幅度界、公共物理单位及逐tile RNE。没有按实际最终输出或抵消程度选择最有利单位。
- 同环境重新运行原始BF16完整WT2，292窗/299,077目标，PPL11.5364289819，与此前门禁一致。模型、源、文本和token身份核验通过。

这是同一高精度前向事件的局部数值重放。GU的FP24变化没有反馈到后续层，也没有据此重新生成Wd事件；**本次不是FP24模型PPL**。现有sigmoid入口保留P8重建g的协议，没有切换为另一个RTL raw-g协议。

## 为什么有这个效果

24位定点为覆盖整组保守范围，部分小贡献在逐tile对齐时被舍掉；FP24为每个状态保留自身数量级，因此对较小结果仍能保留16位有效精度。GU使用32位定点时已有充足绝对精度，所以其误差更低；Wd跨152块、尺度跨度更大，FP24的自适应相对精度在本样本中更有利。

浮点也会损失信息。另做的两个构造例子中，较大正负tile抵消，以及151个小项加到大状态，都可出现FP24舍掉小贡献的情况。因此应让FP24进入实际模型前向做少量PPL后再选型。

## 硬件意义与下一步

12槽×128项时，FP24状态载荷为4.5KiB，与24位定点相同；相对32位的6KiB节省25%，相对64位的12KiB节省62.5%。这是状态数据容量，浮点归一化、RNE及共享加法流水线需要另做电路比较。

本轮支持继续验证FP24，保留32位定点作为对照。下一步为真实前向少量PPL，以及同吞吐条件下的“整数计数＋组合指数转FP24”和FP24加法器综合。未修改现有RTL/TLM默认，未产生新PPA，不宣称已减少整片功耗或面积。

同期定点完整WT2已收齐：64位10.628392、32位10.625405、24位定点10.742757；单seed101，292窗/299,077目标。它们属于实际模型前向；FP24本轮只有同事件局部数值重放，二者不混用。完整定点结果见../t64_narrow_state_20261127/FULL_RESULTS_ZH.md。
