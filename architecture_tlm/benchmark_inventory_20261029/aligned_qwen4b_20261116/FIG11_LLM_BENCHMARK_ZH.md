# Fig.11 LLM accelerator benchmark

**片上能量**是片上计算、SRAM 和已计控制等能量。**外存能量**是生成一个 token 分摊的 DRAM 传输能量。项目统一按传输字节数 × 8 × 4 pJ/bit 计价。**含外存总能量**是同一窗口、同一计价边界的片上与外存之和。P-bit 为 15.27 + 173.16 = 188.43 mJ/token。

同条件外部快估采用 Qwen3-4B B1、2K 缓存上下文、完整 BF16 head、250 MHz 与 136.46 GB/s 的 LPDDR。两个时延端点分别按 80% 有效外存带宽、逐算子计算与访存重叠或串行估算。原报工作保留作者配置。面积另注原始面积范围。破折号表示此口径缺可引用数值。
