# FP状态指数范围与整数编码接口

2026-11-27，Issue225 / PR266。第一部分读取已封存的真实Qwen3-4B T64轨迹，统计每个tile、每次跨块更新后状态、最终值的非零无偏指数；零单独计数。不能只看最终g/u而忽略中间抵消和小贡献。

比较E8/M15基线、E6/M15（22位存储）、E5/M15（21位存储），以及保持24位总长的E6/M17。临时tile转换保持E8指数，存储位数缩减只作用于每次写回状态；报告两阶段各自上下溢。缩窄指数需要重新偏置，不是直接截掉E8的高位。E6偏置31覆盖正常数指数−30..31，E5偏置15覆盖−14..15。观测安全范围不是任意输入的数学保证。

同时以符号、指数、16位有效数整数实现S/S2共享尺度选择、P8幅度码、从原始g生成S8/F3 sigmoid地址，以及P8重建g对应的地址。与现有数值参考逐项核对；两种sigmoid入口各自保持，不混称。所有转换保留RNE、饱和及满幅256旁路，不能仅截取最高8位有效数。

本地及两项Slurm任务内各6项单测通过，包括所有指数跨度的随机P8/S8编码、E5/E6边界、零、W8 PoT量化与E8原格式等价。已有6文件FP24软件源作为只读依赖，执行前核对其SHA。此处没有新RTL/STA/PT或TLM默认修改。
