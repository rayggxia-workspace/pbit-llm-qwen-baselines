# 固定g数制的FSM真实模型试测

用户要求实际测试，而非只给函数探针。沿用Issue175/PR176，前级W8、x四档固定尺度、共享64、T=K64，Qwen3-4B后训练36层FFN，准确SDPA。8段×128目标后缀，三seed；不是完整WT2，不训练，不更改旧快照。

g不做逐输入最大值或四档选择，统一使用幅度8位＋符号：q=RNE(|g|×256/G)，饱和0..255。G=8或16是固定物理单位，等同固定二进制小数点，不能说没有范围编码。过大g会截断，诊断逐层报告截断率和零码比例。u沿用TRAIN固定四档[S/2,S/8,S/32,S/128]。

FSM每个输入从状态0开始，64或128拍，不额外预热。每拍：输入R8比较q→状态饱和加/减1→读取该状态P8输出系数→独立R8比较→与独立u比较结果AND→直接固定W8 Wd。事件在Wd输出列间共享；实现逐拍历史，不用Binomial代替有记忆的输出。数值模拟以Philox提供各路R8，未指定物理/数字随机源电路。

系数离线拟合目标：正分支SiLU(Gq/256)/G；负分支|SiLU(-Gq/256)|/Sf。真实G在非线性内部，不是G×SiLU(q/256)。负分支Sf测试0.5和G：前者提高事件密度，但系数必须在[0,1]，未保证该FSM能拟合。输出符号及Sf×Su通过Wd部分和移位恢复。

四组(G,状态数,Sf负)：(8,4,0.5)、(8,8,0.5)、(16,8,0.5)、(8,8,8)。各组包括同轮BF16；固定g数制＋P8 SiLU表条件均值；FSM有限64/128拍条件均值；FSM实际64/128拍。概率项各3seed，总64份计分（不同状态重复的控制仍单独核验）。根据先前函数探针发现短流启动偏差，使用有限T状态占用拟合，theta0固定0确保g=0严格零；这是我们变体，不是论文精确复现。

条件均值仅诊断量化/函数近似；实际采样有输入、状态输出、u三个比较器，不宣称从三流改两流就节省一个随机源。无z重新统计重编码；Wd整数加权归约与RNE BF16沿用原验证路径。前级gate/up恢复仍FP32参考边界，未完成整FFN bittrue/TLM/RTL/PPA。前级64拍与后级64/128拍串联，至少128/192拍再加归约、转换和访存，不能称整个FFN只64拍。

本机两项CPU测试通过，两项CUDA逐拍/统计对照必须在Slurm分配内通过，才开始模型。原模型/语料/校准SHA及执行快照写入provenance；最终完成只从complete.json及documents/sidecar SHA判断。
