# 给模块开发 AI：接入整机 TLM 需要交付什么

更新：2026-10-30；Issue #217。适用 FFN、Attention、随机服务、转换、存储接口等局部改进。

**请把你的模块整理成“模块说明＋参数表＋已有代码/结果的索引”。我们据此替换整机里的对应部分，不需要你重新写一套完整 TLM，也不要求为了接入而补齐所有 RTL。**

整机继续使用 `architecture_tlm/unified_v6/`。本目录是交付格式建议，`PROFILE_TEMPLATE.json` 目前不是整机能自动加载的配置；首次接入仍需对应的小型适配。已有任务按原 Issue/PR 继续，不另建重复实现。

## 1. 最少交付两份小文件

| 文件 | 写什么 |
|---|---|
| `HANDOFF_ZH.md` | 下面六项信息，通常一至两页；说明本次改了什么、替换谁、哪些未知 |
| `profile.json` | 复制本目录 [PROFILE_TEMPLATE.json](PROFILE_TEMPLATE.json) 填写，便于取参数和绑定版本 |

代码、RTL、测试、原始报告已有就给**准确路径/提交及 SHA-256**，不要再复制大包。若时延随输入或重试变化，额外给一份小型事件表或可运行的服务模型；不必为固定流水模块写事件表。

未知数值用 `null`，同时写预计依据或待补项。确定不发生的动作才填 `0`。证据状态按“功能、时序、能量、面积、模型质量”分别记录，不用一个“已完成”概括。

## 2. 模块说明必须回答的六件事

| 项目 | 最少需要的信息 | 为什么需要 |
|---|---|---|
| **① 边界与工作单位** | 输入到哪里、输出到哪里；一次是一拍、一个采样、一个点积、一个 tile 还是一个 query；形状/适用参数；替换旧模块的哪部分 | 防止把每点积能量当整矩阵能量，或新旧模块同时计费 |
| **② 数制与算法** | 输入/输出位宽、符号、尺度/分组、舍入/饱和；采样数、分层规则、精确计数或 OR；内部累加位宽和跨块对齐；近似是否改变 | 确保模拟的是电路能实现的运算；尺度不能省略成“INT8” |
| **③ 时间与并行** | 标定时钟；首个有效输出延迟 L；接受下一份输入的间隔 II；一次输出多少结果；物理实例数；启动/排空、暂停/反压行为 | 延迟、吞吐和复制硬件是三件不同的事 |
| **④ 存储与随机请求** | 每工作单位从哪个端口读写多少、访问顺序/步长和复用；本地状态/缓冲大小及生命周期；随机数位宽/数量/共享及供给速率 | 整机负责映射 bank、链路和 DRAM；局部不能只给数学字节数 |
| **⑤ 能量、面积及包含项** | 每工作单位能量或可换算的原始功率/窗口/完成量；空闲/保持功率；单实例面积；PVT/频率/激励；哪些外围已经包含 | 防止把活动功率乘整机时间，或重复加 RNG、SRAM、比较器、恢复电路 |
| **⑥ 来源与验证** | 代码/配置/结果版本和 SHA；已有仿真台账 run ID；实际验证命令与结果；未测项；可供复现的一条小用例 | 后续更新可追溯，不依赖聊天记忆 |

填不下的条件可写在说明里，JSON 引用该小节即可。没有实测数据时可以先提供宏模型和合理区间，明确哪些参数是估计；不必等完整电路签核才进入候选 TLM。

## 3. 时间、读写和计价的统一口径

**时间：** 请明确 L/II 的单位和起点，例如“接受输入后第 8 拍输出，II=1”。同一条可持续流水线连续接受 16 份输入，无停顿时最后输出为 `8 + (16−1)×1 = 23` 拍，不是 `8×16=128` 拍。整机内部时间单位是 ns：`时间(ns)=周期数×10^9/时钟(Hz)`。

只有有限缓冲和资源允许时才可重叠。当前 `Scheduler.reserve()` 会占住指定资源直到结束；不能只在 JSON 填 II=1，就认为现有调度器自动支持流水。适配时要同时表达发射占用、结果依赖和在途容量。100MHz 的 STA 不能直接当作 500MHz 达标；可保留“相同拍数、目标频率未验证”的条件情景。

**可变采样：** 除总采样数，还需给初始化/预热、每轮更新、仲裁/拒绝/反馈、有效地址输出和结束规则。平均轮数不足以决定调度，至少提供代表性序列的“相对输出周期＋输出数/重试数＋随机请求”；附输入尺寸和 seed。仅有平均值时也可建粗模型，但保留该近似。

**读写：** 区分外部端口流量与内部寄存器活动。例如权重每 tile 装载一次，采样期在 CIM 内驻留使用，就写清楚，不能每次采样再收费一次普通 SRAM 完整读。部分和留本地计数器、跨 tile 才写出时，也不能每拍写回 SRAM。输入/输出张量大小不自动等于 DRAM 实际流量；说明访问、复用和驻留条件，物理突发/缓存复用交给整机后端处理。

**随机：** 分别给唯一新随机字数量、位宽、共享范围、并行需求和 seed/重播规则。一个 R8 字广播 64 路仍是一个字，不是 64 个独立字。分层/重放/双轴联合采样与 IID 分开；相关性是否经过应用验证要说明。当前可先采用本地邻近 PRNG 接口，不额外存完整随机流；必要的源内部状态和算子编码/计数状态仍须说明。

**能量：** 优先给每工作单位能量。若只给功率，须同时给对应窗口时长和窗口内完成量：`E/次=P×窗口时长/完成次数`。标明该数是总活动能量，还是扣除某种背景后的增量；背景/漏电包含在哪里写清楚，不能重复加。跨频率外推另作假设。每帧、每输出、每采样、每 bit 的价格不可混用。

**面积：** 给测量边界内的单实例面积、其中已有多少并行 lane，以及需要复制几份；不要把一个已经含 64 lane 的 tile 再乘 64。保留原始面积和折算状态；本项目指定流程由 raw 到 55nm 等效只乘一次 `0.81`，其他工艺不套用，功耗/时延不随之缩放。共享硬件只计一份，不按每个调用层复制。

## 4. 我们当前两类模块要特别补什么

| 模块 | 除通用信息外，请优先交代 |
|---|---|
| **FFN 计数/恢复/CIM** | 点积长度、输出列数；固定权重还是双随机；x/g/u/W 各自尺度与共享；T/K；OR 分组；计数/桶/部分和宽度和保持位置；装载、采样、对齐、恢复分别多少拍；是否删掉旧流水寄存器或 SRAM 访问。若只优化计数后端，勿把 RNG/SNG 或整个 FFN 都算作已替换 |
| **Attention 筛选/赢家保持/校正拒绝** | 边界是“分数向量→地址”还是已含 QK/V；候选维度、有效掩码与编码；第一地址何时产生、后续地址速度、重复地址/多 1/全 0/超时怎么处理；源与仲裁是否已含；候选 K/V 位置及 GQA 共享/并集。重试和丢弃也要计工作量；输出地址后 V 读取/累加由哪一端负责 |

例如，一个“输入 128 个 logits、输出 S 个地址”的模块，不能把“128 个 p-bit 一起更新一次”同时写成“整个 query 一拍完成”。另一方面，若地址逐个可用，V 读取允许开始的时间应逐个给出，不必强制等全部 S 个地址生成。上述数字只是交付说明示例，不是当前最优配置。

## 5. 接入时分两种改动，不必每次重做全部模型

| 改动 | 接入方式 |
|---|---|
| 仅换标定价格，边界/事件数/时序/读写均不变 | 更新 profile 和来源，移除旧收费项，重算账本；可复用完全匹配的已封存活动 |
| 改了采样/数制/流水/并行/状态或读写方式 | 更新局部适配与受影响参数，重新调度；数值/随机规则改变时另外标明质量待验，不能继承旧 PPL |

交付时列出“替换的旧 stage/action、保留的外部模块、内部已经收费的部分”。不认识整机 action 名可以先给旧路径及功能边界，由接入方定位。

接入方再做一次小用例和固定整机配置的前后对照，输出时间/能量/面积/流量变化、实际模块版本和未知项；先不要求全参数扫描。正式随机对照遵守项目三 seed 规则。局部 RTL/PT 通过、TLM 成功运行、整模型质量通过要分别报告。

已有 PPA 继续引用 `digital_circuit_simulation_registry/`，新增仿真按原流程登记；本目录不另建功耗数据库。现有代码入口：[统一基线](../BASELINE_ZH.md)、[资源/账本](../unified_v6/core.py)、[整机接入](../unified_v6/model.py)、[FFN](../unified_v6/ffn_latest.py)、[tile 流水](../unified_v6/tile_pipeline.py)。核对版本为 main `7d42c7d30fa9c729c899ba7f815332dd6ed5671a`；未合并模块使用各自 PR 的准确提交。

## 6. 可以直接转交给其他 AI 的指令

> 请按本文件，把你负责的模块整理成 HANDOFF_ZH.md 和 profile.json。先定义一次工作的边界、数据/尺度与采样规则；再给首输出延迟、输入间隔、输出速度和并行实例；说明真实端口读写、本地状态和随机请求；提供已有功耗面积及包含项、代码/配置/结果路径和 SHA。缺少的填 null，注明估计依据，不要猜成已测。不重写完整 TLM、不复制大文件、不更改其他成员成果。若只更新价格，指出旧收费替换关系；若改变了流水、算法或流量，给一条代表性执行序列或现有可运行模型，方便接入统一调度器。更新你原任务的 Issue/PR、STATUS 和交接，并明确这次有没有完成整机接入。
