# 截断、固定分组尺度与随机计算电路

2026-10-19，Issue39。本文把既有实测、论文做法和电路推导分开；新增PPL另见本任务结果。没有新增工艺仿真或实测能耗。

## 1 为什么缩紧幅度有可能改善精度

对一个未截断乘积，以幅度尺度SA/SW和独立随机流表示a/w。每拍AND的概率是|aw|/(SA·SW)，T拍恢复为SA·SW·计数/T。忽略8位舍入时，其方差为：

```
乘积估计方差 = [ SA×SW×|a×w| − (a×w)² ] / T
```

因此，在值不变、尚未裁剪的区间内，缩小尺度可降低恢复到真实单位后的绝对噪声。目标不是让概率恰好0.5，也不是把直方图做成均匀；固定尺度下Bernoulli在p=0.5反而方差最大。

超出S的幅度截到S、概率固定为1，可消掉该侧的随机性，但产生不会随T消失的偏差。应平衡裁剪偏差与采样方差，并用PPL检验。当前输入A共享64路，点积还含协方差，不能用上述单项公式忽略组内相关；实验继续使用准确联合输入计数。

## 2 这在已有工作中如何处理

|原始资料|实际做法|可借鉴与边界|
|---|---|---|
|[Sim & Lee，SC-CNN，2020，§4.3](https://pmc.ncbi.nlm.nih.gov/articles/PMC7793640/)|明确容许少数大值越界饱和，收紧量程提高其余值精度；限定二次幂尺度并逐层搜索|直接支持本次量程实验；该文乘法本身为确定优化位流，不能继承成自然IID短流精度保证|
|[ACIQ，2018](https://arxiv.org/html/1810.05723v1)|优化量程内量化误差与量程外裁剪误差|我们还需加有限T随机误差；不能把CNN阈值直接套Qwen|
|[SmoothQuant，ICML 2023](https://arxiv.org/abs/2211.10438)|用校准数据及等价通道缩放分担激活/权重离群幅度|离线校准可行；迁移到权重的范围也可能增加，需联合检查|
|[OCP MX标准v1.0，§6](https://www.opencompute.org/documents/ocp-microscaling-formats-mx-v1-0-spec-final-pdf)|组内元素共享二次幂尺度，组内点积乘两侧尺度后跨组求和|不是随机计算，但证明这种数制/归约边界属于成熟块缩放设计|
|[DS-CIM，2026，§IV/V](https://arxiv.org/html/2601.06724v1)|LLaMA实验先FP8再以128粒度对齐INT8；SRR通过移位/区域映射建立OR互斥，同时优化PRNG|其完整范围校准细节并未充分公开；SRR不等于裁剪，优化序列的精度不能直接归给自然IID|

我们的固定尺度方案仍由自然IID随机字直接比较生成随机流，不要求预设序列或挑选seed。尺度优化、概率格点、相关性设计是不同问题。

## 3 是否可以预先确定

**权重可以完全离线确定。** 它是常数，每层每组的范围、指数和概率阈值可在写SRAM前准备好。推理无需重新求权重最大值。

**激活可以从train校准固定，但无法保证未来输入全部落在范围内。** 本次使用原模型前8192个train-token，4个独立2048上下文，每层每64通道汇集绝对值，预注册99.9/99.99分位。推理不在线求最大值，但需承受越界；传播后的随机x/z与原teacher统计也会不同。需报告独立test上的实际截断率和PPL，不能只以校准覆盖验收。

固定范围的上限取2^ceil(log2(S))，因此比原阈值最多宽一倍；覆盖更保守，随机噪声也可能比任意实数阈值更大。向下取幂会增加截断，两者不能混称。

## 4 电路到底增加什么

设第b个输入组幅度为2^eA[b]，第o输出行的该组权重幅度为2^eW[o,b]；C[o,b]是该64输入组T拍的带符号AND计数。T=2^t时：

```
输出y[o] = 对各组b求和 { C[o,b] × 2^( eA[b]+eW[o,b]−t ) }
```

**先完成组计数，再移位对齐，再跨组累加。** 不可把不同组的计数直接混成一个总数，然后恢复唯一尺度。可每T拍完成组计数后移位一次，避免每拍每连接都恢复幅度。

|部分|固定二次幂的实现|仍有的成本|
|---|---|---|
|组尺度统计|train/权重离线准备|指数表读取、配置；省在线absmax树及一般倒数|
|BF16→概率幅度|指数对齐、尾数移位、舍入/饱和|每个BF16元素指数不同，仍需转换逻辑；不是免费接线|
|组计数幅度恢复|指数相加、移位|不同指数跨度要求宽累加器，或显式右移舍入误差|
|专用固定范围单元|常数移位可接线/位切片|仍须输出统一数制、处理溢出|
|时分复用单元|共享AND/计数阵列＋可配置指数/移位|小控制/指数表、可选移位器、路由|
|严格p=1|sat OR (R<q)，或特殊端点码|必须说明端点状态存储/生成，不能把q255当作原比较器的1|

估计量级：一个W位、K档移位的桶形移位器约需W·ceil(log2K)个2:1 MUX，另加控制。这个是逻辑量级，不是面积/功率百分比。不同组指数跨度Δe还会增加对齐累加宽度；若统一到最小LSB，约需增加Δe位及跨组保护位。gate/up每输出14组，down每输出76组。

不必为所有分组各复制一种矩阵电路：相同AND/计数阵列只需配置指数。少数固定量程阵列可以考虑，但分配、互连、负载不均衡也要收费，未证明优于复用阵列。

## 5 元数据可确切算到多少

Qwen全部24层三个FFN矩阵共313,786,368个权重，原signed INT8载荷299.25MiB。每输出行×64输入分组，有4,902,912条尺度；旧64×64 tile仅76,608条。虽然条目增加64倍，**不等于总存储增加64倍**。

|每条尺度|全模型尺度总量|占原W8载荷|
|---|---:|---:|
|5bit指数（需验证跨度够不够）|2.922MiB|0.977%|
|8bit指数|4.676MiB|1.563%|
|BF16实数|9.352MiB|3.125%|
|FP32实数|18.703MiB|6.25%|

固定x/z每层14+76=90条，全24层2160条；8bit指数合计2160字节。以上是位打包容量，不代表SRAM宏面积比例；端口、bank、字宽对齐、ECC和片上同时驻留部分另计。

幅度8bit与独立符号共9bit，不是signed INT8总8bit。若全部权重显式存A8+sign，另多37.406MiB（12.5%）。若还为每权重保留一个独立饱和标志，又多37.406MiB；可选特殊满幅码以省flag，但会更改顶端概率格点，需另测。动态激活flag只需当前tile，不能按全权重永久存储计。实际权重布局可保留原signed码再导出阈值，不应同时默认存两份。

INT8只规定码值范围，不规定模型分布均匀。权重也集中在小幅度，但旧z有99.131%落q≤15，问题严重得多。旧W8已量化为零的权重约1.85%～2.16%，row64重编码没有恢复它们。当前量程实验从同一W8出发，是为隔离尺度作用；不能冒称已优化原BF16权重量化。
