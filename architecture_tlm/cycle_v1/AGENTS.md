# Cycle execution maintenance

- Keep `unified_v6` and historical result sets unchanged. New timing or numeric mappings require new configuration/results and explicit evidence boundaries.
- Event skipping must preserve every observable stall-reason transition, including dependency/CDC visibility while a resource remains blocked and partial bank release. Compare full traces and memory/state/actions with the clock-by-clock reference; equal finish times alone are insufficient.
- Memory program order follows operation registration. Register dynamic memory writers before their dependent memory readers, or the RAW/WAR scoreboard can correctly detect a contradictory cycle. A control node may await a future producer; create its downstream memory accesses in the completion callback.
- Runtime-created activation/KV writes must depend on their actual producer and use the declared CDC visibility. A `born_ps` next-edge restriction alone is not a multi-stage CDC contract.
- Include transitive imports outside the main package and runtime data such as `architecture_tlm/random_service/shared64_mapping.json` and the v6 SRAM calibration JSON in server snapshots. Hash every source/data file and run both the cycle FFN and v6 bridge from a fresh extracted snapshot with isolated Python and no inherited `PYTHONPATH` before submitting an expensive matrix.
- Bit-plane mappings must preserve input-sign rails and signed two's-complement W8 bit weights when referencing the existing RTL. Equal numerical output and equal storage size do not establish identical bit-plane activity or PPA.
- An ordered consumer with finite response storage needs bounded, ordered prefetch eligibility. A byte-credit limit alone permits later sparse-address responses to occupy all slots while the first needed response cannot issue. Test physical IDs whose numeric and lexicographic orders differ, with fewer slots than unique reads.
- Bound dependency-build parallelism at every layer to the scheduler allocation, including Conan's CONAN_CPU_COUNT and CMAKE_BUILD_PARALLEL_LEVEL; an outer make -j value alone may not constrain package recipes.
- A shared multi-consumer cache also needs bounded directory/consumer metadata, explicitly timed runtime unions, and operand-response credits held until each MAC completes. A bounded source cache alone does not bound copied responses waiting for consumers; use a common token order to prevent credit deadlocks.
