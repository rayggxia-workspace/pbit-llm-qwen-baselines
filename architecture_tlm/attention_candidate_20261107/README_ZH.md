# 新Attention接入审核：PV128＋归约32＋共享QK

2026-11-07，Issue225/PR248；模块来源Issue198/PR199的本地最新交接。结论：**可以接入候选TLM接口；按现有标定单价，整机覆盖面积预计52.6217→41.4630mm²，减少11.1587mm²／21.21%。尚不能称新的硬件实现已验收。**

当前宿主保持1216KiB SRAM、100MHz、640路普通FMA、12个C20公共FFN核、GU状态96KiB、前8后32、2K/K128/赢家S64。不是TT250方案，不更改原默认或已冻结执行源。

## 2. 能接什么，尚缺什么

|项目|实际状态|接入处理|
|---|---|---|
|1216KiB/640路宿主、T8/T32接口|本轮实例接入检查通过|可作为显式候选安装|
|PV有限两字缓存、采样维度顺序|原模块本地压力检查通过|复用原候选actor|
|QK共享时分租用|模块前缀回放通过|仍是旧供数宏下的资源租用|
|QK共享FMA16/C4切片|三seed RTL及门级通过|不代表真实SRAM供数已验证|
|单头PV4新电路|RTL通过，门级首帧仍X|不回填其失败DC面积，不作正式后端|
|真实K布局→共享FMA接口|尚未完整native接通|不得把重排、mux和路由写成免费|
|新组合完整36层时序|本轮未运行|不把模块前缀和冷head代替整机|

41.46mm²使用旧已标定标量ADD、状态、控制与保持存储单价作组件拆减，**没有使用门级失败PV4的0.085667mm²/头DC面积**。共享FMA新切片0.244929mm²接近旧裸切片0.244870mm²，但不是严格同条件配对，不据此声称mux开销已精确标定。新QK重排/路由、PV状态选择与时钟门控映射增量PPA仍缺。

## 3. 本轮接入适配

正式入口`integrate.install(model, owner_install, 'combined32')`，在原宿主构造后、首次事务前调用；owner_install为已核SHA的`attention_resource_compaction_20261107.model.install`。原Attention源只读，未复制原件到Git。外部复现需要先取得同SHA原模块和既有runtime，不能把本PR称为包含所有上游未发布源码。

发现原候选actor虽更新resource_contract，但继承的整机executed_resources仍可能写512路独立QK、512路PV、128路归约。本适配器按候选合同改成：独立QK0、逻辑QK服务512、PV128、归约32、普通池640。这样接回面积/吞吐账本时不会重复收费或误读资源。硬件未验收项显式保留，不提升生产默认。

本轮9项本地检查通过：含原模块3项有限PV/四头/归约检查、真实宿主T8/T32接入、继承资源账本修正、另一宿主不受影响、整机面积边界、失败PV价不被使用、归约8不被静默采用；原模块10个原生结果原件逐SHA复核。无新GPU/EDA/PPL/RTL/PT任务。
