# Issue 116 周期后端独立验收

审查基线：`46804fb3a1c50b29a19a7d0a3da6bb8f8b59af7d`。本清单由未编写执行核或运算核心的审查代理，依据用户的《01_TLM周期级深化与模拟器改造方案.md》、现有 `unified_v6` 和 `digital_ppa_v1/LATEST_TLM_RTL_GAPS_ZH.md` 建立。

这里列的是验收门槛，不是已通过的检查。执行回执将另存，未运行或被缩小的范围必须保留。逐拍与事件实现共享数学算子可以，但不能把共用同一调度函数的两种循环称作独立周期验证。

|---|---|---|
| C01 | P0 | 同拍只消费明确定义的旧状态；颠倒无依赖模块注册顺序及同刻事件入队顺序，外部可见接受/完成时间、结果、动作不变；资源仲裁优先级是例外，必须显式配置 |
| C02 | P0 | latency 与 II 各自约束。用 latency=5、II=1、2 实例和连续输入推导首输出及稳态输出时间；下游长堵塞不丢输出、不免费覆盖正在使用的状态 |
| C03 | P0 | 有限队列/在途/缓冲容量始终满足 0<=occupancy<=capacity；从预留到最后消费者释放完整计账；两个消费者、两个核心争缓冲、容量恰好/少1、同拍释放再申请全部明确 |
| C04 | P0 | 同 bank 请求按仲裁规则序列化，不同 bank 在允许的端口数内并行；读后写、写后读、多个请求者回压不返回陈旧或串主数据 |
| C05 | P0 | 100 MHz 与 80 MHz 用整数公共时间轴精确表示；跨域返回须经规定同步沿；连续流测试不能把每项无条件加完整CDC等待串行化；异步相位和边界前后均覆盖 |
| C06 | P0 | DMA拒收时保留同一请求/地址/ID直到真正接受；乱序回调只解锁所属依赖；重复/未知完成报错；接受数=完成数+在途数，无幽灵完成和重复计费 |

| F04 | P0 | 每份驻留权重和计数/累加状态有真实生命周期与字节量；预取与计算重叠必须同时占两个有限槽；输入x重复使用有保持或重读动作 |
| A01 | P0 | 全零/单命中/多命中、连续拒绝、赢家保持和切换、fair越界重试；被拒绝提议消耗服务和随机帧；达到上限明确失败，不制造接受样本 |
| A02 | P0 | 候选数N、请求/保留样本S、提议、拒绝、随机帧及服务/等待时间分别记录；N>P有ceil(N/P)服务波；N>容量分批或报错，不截断 |
| A03 | P0 | 候选地址故意不连续并含GQA共享；实际K/V物理请求只覆盖所需地址与突发扩展。重复样本去重读后仍按重复次数累计数学权重；重复winner不记成独立IID样本 |

| E01 | P0 | Link与DRAM后端只有一个时序权威；访问提交时间由当前执行状态产生，完成回调决定后续。静态trace回放明确不是在线闭环 |
| E02 | P0 | 模块宏价与子动作互斥，PRNG/FFN共享广播/恢复/存储不重复收费；未知PPA保持null，activity与idle功耗边界明确 |
| E03 | P0 | 合成输入、冻结真实tensor、真实全模型执行、RTL功能、STA、布局前功耗分别标注；自有核一致性不升级为电路频率或全模型质量证据 |

外部对照的最小可实施方案：先用现有 `nr_sram_router` 的固定优先级、单响应槽和非旁路释放语义，生成同一请求/回压表分别喂给RTL和周期后端；逐沿比较 `req_valid & req_ready`、`rsp_valid & rsp_ready`、地址及数据。DMA旧RTL只用于窗口边界/拒收保持/排空对照，新后端乱序ID必须独立scoreboard验证。只有新增真实双时钟FIFO/握手RTL，才可将CDC对应项标为RTL验证。算术RTL可证明有限子模块的固定格式数值，不证明完整SC帧反馈和阵列供数。

本轮停止条件：P0未闭合时不得将相应路径描述为已正确实现；可交付明确受限的prototype和失败证据。P1未做项列入后续工作，不将其通过情况从旧PR继承。
